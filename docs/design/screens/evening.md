## 診斷（`diagnosis.html`）｜AC-15（D0 決定 Q-34）
- 焦點卡：停頓 >2 秒 4、贅詞 9、每分鐘字數 96，各附上週平均。
- **手機**：三段切換「逐句對照（預設，上下排）／你的回答／Senior 版」，切換只換顯示，不換頁。
- **電腦**：左右雙欄＋欄標題，逐句對齊；標記 hover 有說明。
- 圖例：文法（波浪線）、贅詞（刪除線）、太口語（底色）、停頓（膠囊）、升級語塊（粗底線）。
- 標記可點：點一下（或 Tab＋Enter）在該句下方開說明（例「have　文法：have → had」），再點、按 ✕ 或 Esc 關閉；點擊範圍擴大到 48×48，字本身優先。電腦 hover 另有短提示。
- 不支援 `:has()` 的瀏覽器：切換列隱藏，固定顯示「逐句對照」（原逐字稿一定看得到）。
- 升級語塊清單（AC-16）：列出 3～5 個，標題「勾選要加入的語塊（最多 5 個）」，不強制最少；圓形勾選（電腦 1–5），主按鈕「加入明天的新卡（3）」即時計數。
