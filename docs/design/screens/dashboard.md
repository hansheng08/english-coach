# 儀表板＋打卡日曆（D-005，D2b 第 1 批）｜AC-21、ARCH §4.8.3
原型：`records.html`（「紀錄」分頁的第一個子頁）。截圖：`shots/records-*`。
依據：PRD AC-21（早中晚三格打卡日曆、streak 天數、四個狀態各自的卡片數；Mastered 數是頁面最大字級的數字；時段全部步驟完成才打勾，僅進入或有步驟跳過用另一種可區分、非勾的標示，未進入不顯示標示）；DESIGN §8「時段標示」三態（完成＝實心條＋勾；有進入沒全部完成＝斜紋條＋跳過圖示；未進入＝空軌、無標示）與 streak 條件文案；ARCHITECTURE §4.8.3（`slot_checkin` 事件、完成／打開的判定、streak＝一天裡三段都有 `opened`）、§5.1（讀取類直接用 supabase-js 讀表）。

## 1. 版面
- 頂部：分頁標題「學習紀錄」＋子頁切換 `.subnav`（儀表板／成長曲線／練習紀錄，三個 48px 連結，`aria-current="page"`）。底部分頁「紀錄」為選中。
- 手機（由上到下）：Mastered 卡 → 連續卡 → 字卡狀態 → 打卡日曆 → 當天明細。
- 電腦三欄：左＝Mastered、連續、字卡狀態；中＝打卡日曆；右＝當天明細。
- **Mastered 卡**：數字用 `font-size-display`（2.75rem），是全頁最大的字（AC-21）；下方 M2 量尺（同首頁 `.m2`，刻度 15／60）。
- **連續卡**：數字 1.75rem＋一句「三段都在時段內進入第一步，就算一天」（DESIGN §8 用「進入」）。
- **字卡狀態**：2×2 格，四種狀態各一格：狀態標籤（沿用 `.state` 的形狀＋文字：Collected 空心圓、Learning 半圓、Reviewing 實心圓、Mastered 金色菱形）＋卡片數。右上「共 N 張」。

## 2. 打卡日曆
- 一個月一張表（週一開頭，`<table>`＋`<th scope="col">` 星期）。每天一格，格內：日期＋三條（由上到下早、中、晚）。
- **預設顯示本月，可以往前翻**（PM 2026-11-27 決定：F9 要有累積感，M1 要看連續 8 週）。標題右側「上個月／下個月」兩個 48px 圖示按鈕（`aria-label` 寫出月份）；已是本月時「下個月」disabled。最早翻到開始使用的那個月。
- 每條三態（照 DESIGN §8，AC-21）：
  - 完成：綠勾圖示＋實心墨色條。
  - 有進入、沒全部完成（含跳過）：跳過圖示＋斜紋條。不是勾。
  - 沒有進入：只有空軌（細框），沒有圖示。
- 今天：格子 2px `gold-text` 框。還沒開始使用的日子與未來的日子：只有日期（淡色），沒有三條。
- 圖例在表下方：「這段全部完成」「有進入，沒全部完成（含跳過）」「沒有進入」「今天」。
- 讀屏：每格內有隱藏文字，例「11/24：早上完成；中午完成；晚上有進入，有跳過」。三條本身 `aria-hidden`。
- 格子**不可點**（PM 2026-11-27 決定，本版沒有單日明細頁；手機格子約 38px 寬也不足 48px）。要看某天的細節，用右欄／下方的當天明細與「看這天的練習紀錄」連到練習紀錄。

## 3. 當天明細
- 今天一張：早、中、晚三列，各列「完成／有跳過／沒有進入」標籤（形狀＋文字）＋一行說明（完成的步驟、跳過的步驟名稱、或晚上還沒開始時「21:00 開始，23:59 前打開第一步就不中斷」）。
- 最近一次沒全部完成的那天一張，含「看這天的練習紀錄」按鈕（→ `log.html`）。
- 中午只有一步（Q-41）：完成＝當天排定的卡全部答完，明細寫「字卡複習 25／25 張答完」；有進入沒答完＝「有進入，沒答完」（日曆讀屏文字同）。不列題型。
- 中午排入 0 張且已打開複習（PRD v1.6 AC-26／Q-42，已決定）：算完成，日曆用同一個「完成」標示（實心條＋勾）；明細寫「字卡複習 0／0 張答完・今天只有 0 張」；讀屏「中午完成（今天只有 0 張）」。尚未打開時仍是「沒有進入」。原型示範：`records.html` 11/11（三）那一格與「中午 0 張的完成例」明細。
