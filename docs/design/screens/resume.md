# 履歷與面試題（D-005，D2b 第 1 批）｜AC-11、AC-12、AC-13、NFR-04
原型：`resume-empty.html`（還沒上傳）、`resume-generating.html`（處理中）、`resume.html`（有履歷＋題目）、`resume.html#del`（刪除確認，截圖檔名 `resume-del-*`）、`resume-deleted.html`（刪除完成）。截圖：`shots/{resume-empty,resume-generating,resume,resume-del,resume-deleted}-*`。
依據：PRD AC-11（上傳英文履歷 PDF 或 DOCX，60 秒內產生 ≥ 15 題，自我介紹／行為題／技術題各 ≥ 3，每題標示引用的履歷經歷；新上傳的取代舊的）、AC-12（點「刪除履歷」→ 原檔與解析文字從雲端刪除，之後產生的題目不再引用，並顯示刪除完成）、AC-13（有履歷題只出履歷題，沒有時從題庫出題）、NFR-04（只供本人練習；送 AI 前移除電話、Email、地址；可刪除）；ARCHITECTURE §3 `resume`／`question` 表、§4.9 第 4 點（刪除＝先 retire 履歷題、再刪 `resume`、再刪 Storage）、§5.1 `POST /resume`（≤ 60 s）／`DELETE /resume`（≤ 5 s）、§7（瀏覽器端解析＋去個資，原檔放私有 bucket）。

## 1. 狀態
| 狀態 | 內容 | 原型 |
|---|---|---|
| 還沒上傳 | 虛線框上傳區：上傳圖示＋「上傳英文履歷」＋「PDF 或 DOCX。60 秒內產生至少 15 題面試題：自我介紹、行為題、技術題各至少 3 題，每題標出引用的經歷。」＋墨色「選擇檔案」（`<input type="file" accept=".pdf,.docx">`）。右欄：「晚上從內建面試題庫出題。上傳履歷後，晚上只出履歷題。」（AC-13）＋隱私說明 | `resume-empty.html` |
| 處理中 | 檔名＋三步清單：在這台裝置讀出文字 → 移除電話、Email、地址 → 產生面試題（完成＝實心勾、進行中＝金色圈）；右上「約 60 秒內」；「請留在這一頁；完成後這裡會換成題目清單。」；右欄說明換新履歷時舊的什麼時候被取代 | `resume-generating.html` |
| 有履歷 | 左＝題目清單，依三類分組（組標題＋題數），每題：英文題目＋引號圖示「引用：{經歷}」（`cited_experience`）。右欄＝目前的履歷（檔名、上傳日、格式、「已移除電話、Email、地址」）＋「換新履歷」（白底框）＋「刪除履歷」（`bad` 字的文字按鈕）＋「換新履歷會取代舊的，舊題目不再出現。」＋隱私說明 | `resume.html` |
| 刪除確認 | 底部 sheet（電腦置中卡）：「刪除履歷？」＋「會從雲端刪除履歷原檔和解析出的文字。之後產生的題目不再引用這份履歷。」＋「已經練過的紀錄會保留。沒有履歷時，晚上改從內建題庫出題。」＋紅底「刪除履歷」＋「取消」 | `resume.html#del` |
| 刪除完成 | 回到「還沒上傳」，上方綠色狀態列（`role="status"`）：**履歷已刪除**　原檔和解析文字都已從雲端刪除。（AC-12「顯示刪除完成」） | `resume-deleted.html` |

- 刪除中：sheet 內紅按鈕改「刪除中…」、disabled。失敗時 sheet 內顯示表單訊息（`.alert`）「沒有刪除成功，再試一次。」（ARCH §4.9：第 1 步成功、第 2 步失敗是安全的中間狀態，重試即可）。
- 產生失敗：用錯誤卡（`errors.md`），原因照 §5.0.4 範本；保留舊履歷與舊題目（新的沒成功就不取代）。
- 檔案不對（不是 PDF／DOCX、讀不出文字）：上傳區下方欄位訊息「只能上傳 PDF 或 DOCX」／「這個檔案讀不出文字，換一個檔案再試」。
- 新元件：`.drop`（上傳區）、`.filecard`、`.qcat`／`.qlist`（題目分組）、`.steps3`（處理步驟）、`.btn-danger`（紅底按鈕，文字用 `bg` 色，淺深都 ≥4.5:1）、`.txt-danger`。

## 2. 入口
- 履歷不是底部分頁。入口：設定頁的「履歷」列（設定頁因 G1 改 AC-26 暫停設計）、晚上題目卡上的「引用你的履歷」可連過來。原型的返回列先回「今天」。

## 不確定
1. 入口放哪裡（設定頁、晚上頁、紀錄頁）→ 等設定頁設計時一起定（PM／Hansheng）。
2. 處理中能不能離開頁面：`POST /resume` 是一次請求（≤ 60 s），離開可能中斷；原型寫「請留在這一頁」→ TechLead（T-036）。
3. 送 AI 前要不要先給 Hansheng 看去個資後的文字（預覽再送出）→ PM（審計 T-035 的可選項，屬 T-036 頁面）。原型沒有預覽步驟。
4. 舊履歷題在換新履歷後是否還出現在練習紀錄（紀錄保留，題目標 retired）→ 設計假設：紀錄照常顯示舊題目 → TechLead 確認。
5. 題目清單要不要顯示「被問過幾次」（AC-13 依此排序）→ PM。原型不顯示。
