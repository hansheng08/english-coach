## 這一輪改了什麼
- 三個全新方向，全部在「iOS 式高級、精緻」範圍內，但材質、色溫、強調色、密度、鼓勵的呈現方式都不同。
- 不學 Apple 活動圈，不用 SF Symbols、不用 Apple 圖像；圖示全部自己畫（inline SVG，1.75 線寬、圓角端點）。
- **全部只用系統字**，字型堆疊：`-apple-system, BlinkMacSystemFont, "SF Pro Text", Roboto, "Noto Sans TC", "Noto Sans CJK TC", "PingFang TC", "Microsoft JhengHei", sans-serif`。沒有打包字型，round 1 的 Barlow Condensed／Literata 在 round 2 都沒用到（見 Q-35）。
- **實際顯示的字型**（Chrome `CSS.getPlatformFontsForNode`，所有 round 2 畫面）：英文與數字＝**Roboto**、中文＝**Noto Sans CJK TC**。也就是說截圖就是 Hansheng 的 Android 手機上的樣子；SF 只會在 Apple 裝置上出現。桌機 Chrome 在 Windows 會落到 Microsoft JhengHei＋Segoe UI 類（未實測，見「不確定」）。
- 每個方向都用 CSS 變數做淺色＋深色（`prefers-color-scheme`），兩頁都有深色版，不只首頁。
- 電腦晚上診斷三個方向都沿用 round 1 C 的「逐句對照」，重新設計樣式；有 hover／focus 狀態、數字鍵 1–5 勾選、畫面上有鍵盤提示。
- 第 1 輪的資料夾和截圖原封不動。

## 自我評審（impeccable critique／audit，看過每張截圖後）
- R2-A：週進度原本是橫條，看起來像漢堡選單 → 改成直立三段膠囊（早在下）；今天的「進行中」原本半格填色很怪 → 改成外框格；分組標題的上邊距被 `:first-of-type` 吃掉 → 修正；手機診斷的「這次的數字」標題在數字隱藏時還在 → 一起隱藏；分組標題灰 #6E7480 在頁底只有 4.23:1 → 改 #666C78（4.76:1）。
- R2-B：琥珀 #E8930C 當圖形在白底只有 2.44:1 → 圖形改 #CC7A00（3.31:1），文字用 #9A5800；電腦版右欄下面太空 → 加「這一週」細字統計；開始錄音按鈕在電腦版原本黏在底部壓住清單 → 移到「現在」區塊下面；診斷列用圓角＋陰影當分隔線出現弧形 → 改成直線。
- R2-C：Mastered 50 個小格太密、像條碼 → 改成一條進度線＋金色 50 目標刻線；診斷列分隔同樣改直線；淺色頁上的主按鈕不用金色（金色在白底只有 1.6:1），改墨藍，金色只放在深色焦點卡上。
- 刻意避開：紫藍漸層、到處毛玻璃（只有 A 的上下列用）、每個區塊一樣的圓角卡（B 無卡、C 只有焦點卡是深色）、emoji、貼紙／印章／吉祥物／彩帶。
- **還沒處理（D2 再做）**：平板 768 仍是手機版面拉寬（沒有橫向捲動，但沒有專屬版面）；錯誤、載入、空狀態沒畫；C 電腦首頁焦點卡下方留白偏多。

## Designer 推薦
**R2-C 夜幕焦點。** english-coach 最重要的一段在晚上，C 的焦點卡直接回答「現在做哪一件」，深色模式也最自然。它的高級感來自材質對比、配色克制和嚴謹對齊，不靠 SF 字型，所以在 Android（Roboto＋Noto Sans TC）上效果不打折。遊戲化保留在柱狀、50 目標刻線和金色數字，克制但看得到進步。
- 想要最接近 iPhone 內建 App 的熟悉感 → R2-A；想要最安靜、像手帳 → R2-B。可以混搭（例如 C 的首頁＋B 的診斷閱讀節奏）。
