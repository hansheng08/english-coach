### B. `_shared/config`（唯一讀 `Deno.env` 的地方；依 ADR-010 決定 1 可 import `zod` 與 `@english-coach/contracts`）
11. `supabase/functions/_shared/config/env.ts`（新增；純函式，**不碰 `Deno`**，Node 可測）：
    - `export type EnvGetter = (name: string) => string | undefined;`
    - `export type SupabaseEnv = { readonly url: string; readonly publishableKey: string };`
    - `export type KeyPresence = { readonly hasSupabaseUrl: boolean; readonly hasPublishable: boolean; readonly hasSecret: boolean; readonly onlyLegacyKeys: boolean };`

## 實作限制
- 相對 import 一律寫 `.ts` 副檔名；跨套件只寫 `@english-coach/contracts`（測試可加 `@english-coach/contracts/testing`）。`@supabase/supabase-js` 只能在 `supabase/functions/_shared/db/**` import。不寫 `npm:`／`jsr:`／`http(s):` import。
- `Deno.env` 只在 `supabase/functions/_shared/config/deno-env.ts`；`Deno.serve` 只在 `supabase/functions/api/index.ts`；其他檔案 import 時不得讀 `Deno`；測試不得 import `index.ts`、`deno-env.ts`。
- `_shared/{config,db}` 的正式程式不得 `throw`（`db` 有 lint 擋；`config` 依 ARCHITECTURE §6 同樣只回 `Result`）；`JSON.parse` 用 `tryCatch`、zod 用 `safeParse`；`router.ts` 只在最外層 `try/catch`。
- 不用 `eslint-disable`、`@ts-ignore`、`any`、`as unknown as`、非空斷言 `!`；`as AuthContext` 只在 `auth.ts`；`@ts-expect-error` 只在 `*.test-d.ts`。

- log 與錯誤訊息只能有變數名稱、布林與錯誤的 `name`；不得有 token、claims、金鑰或任何環境變數的值。
