## 目標（一句話）
在 contracts 加 `NewsSettingsSchema`，在 domain 算出「今天輪到哪一類」與「沒新聞時依序換哪一類、三類都沒有就用舊文章」，全部可重現、可測。

## 範圍：要做（只能新增或修改這些檔案，共 6 個）
1. `packages/contracts/src/settings.ts`（修改；只**加**，`SrsSettingsSchema` 不動）：`NewsSettingsSchema = z.object({ rotation_order, anchor_date, lookback_hours })`
   - `rotation_order`：`z.tuple([NewsCategorySchema, NewsCategorySchema, NewsCategorySchema])`，三類各出現一次（重複 → 錯誤 `path: ['rotation_order']`）；預設 `['ai', 'software', 'semiconductor']`（從 `NEWS_CATEGORIES` 複製，不另寫字串）。
   - `anchor_date`：`PlanDateSchema`；預設值見「不確定」第 1 點（v1.1 補上）。
   - `lookback_hours`：整數 1～168，預設 `48`。
   - `export type NewsSettings = z.infer<typeof NewsSettingsSchema>;`
2. `packages/contracts/src/settings.test.ts`（修改；只**加** `NewsSettingsSchema` 的 `describe`）
3. `packages/domain/src/news-rotation.ts`（新增；只 import `@english-coach/contracts` 與 `./taipei-date.ts`）
   - `export function plannedCategory(planDate: PlanDate, settings: Pick<NewsSettings, 'rotation_order' | 'anchor_date'>): NewsCategory`：`rotation_order[((daysBetween(anchor_date, planDate) % 3) + 3) % 3]`（`anchor_date` 之前的日期也要對：負數取餘）。不用 `!`、`as`；用 tuple 索引或 `switch`。
   - `export function categoryTryOrder(planned: NewsCategory, rotationOrder: NewsSettings['rotation_order']): readonly NewsCategory[]`：從 `planned` 開始，依 `rotation_order` 往後繞一圈，回 3 個類別（例如順序 `[ai, software, semiconductor]`、`planned = semiconductor` → `[semiconductor, ai, software]`）。
   - `export type NewsCategoryDecision = { readonly planned: NewsCategory; readonly actual: NewsCategory | null; readonly skipped: readonly NewsCategory[]; readonly useFallbackArticle: boolean };`
   - `export function decideNewsCategory(planned: NewsCategory, rotationOrder: NewsSettings['rotation_order'], hasNews: ReadonlySet<NewsCategory>): NewsCategoryDecision`：依 `categoryTryOrder` 找第一個 `hasNews` 有的類別當 `actual`，前面沒有的記入 `skipped`；三類都沒有 → `actual: null`、`skipped` 是三類、`useFallbackArticle: true`（§11.2 備援第 3 步；選哪篇舊文章是 `_shared/news`／`daily-prep` 的事，不在本單）。
4. `packages/domain/src/news-rotation.test.ts`（新增）
5. `packages/domain/src/index.ts`（修改；只加匯出）
6. `docs/reports/T-049.md`（新增）
