## 目標
`redactPii` 照下列順序補三個缺口：先把全形字元轉成半形再比對；中文地址認得台灣縣市簡稱（仍要以「號」結尾）；兩個年份組成的區間不當市話。其他規則、輸出形狀、純函式與冪等都不變。

## 介面
```ts
// apps/web/src/features/resume/redact.ts（新增匯出；redactPii 的簽章與 PiiCounts 不變）
/** 全形 U+FF01～U+FF5E 換成對應的半形 U+0021～U+007E，U+3000 換成半形空白；其他字元不變。長度不變。 */
export function foldWidth(text: string): string;
```
1. **全形轉半形（先做）**：`redactPii` 一開始算 `folded = foldWidth(text)`。因為每個字元都換成一個字元，`folded` 和 `text` 的每個位置一一對應。之後每一條規則都在 `folded` 上找範圍，再把**原字串與 `folded` 的同一段**一起換成標記（標記全是半形，兩邊長度仍一致）。所以：
   - 全形的電話、Email、地址會被換掉；
   - **標記以外的字元一個都不變**，全形標點（例如「，」「：」）在輸出裡仍是全形（AC-T35-7 照舊）。
   - 不用 `normalize('NFKC')`：它會改掉標記以外的字元，也可能改變長度。
2. **台灣縣市簡稱（TechLead 定清單）**：`ZH_ADDRESS_RE` 的開頭條件改成「兩個漢字＋市或縣」**或**下列簡稱之一：北市、新北、桃市、中市、南市、高市、基市、竹市、竹縣、苗縣、彰縣、投縣、雲縣、嘉市、嘉縣、屏縣、宜縣、花縣、東縣、澎縣。其餘條件不變：後面一定要有「路、街、大道、巷、弄」之一，並以「號」結尾（可接 `\d+樓`、`之\d+`、`-\d+`）。清單放成一個常數陣列，不散在 regex 裡。
3. **年份區間不當市話**：`TW_PHONE_RE` 命中的字串如果是「區碼（`0[2-8]\d?` 或加括號）＋分隔＋四位數＋分隔＋四位數」，而且兩個四位數**都**是 `19xx` 或 `20xx`，就保留原樣、不計數（寫法同 `US_PHONE_RE` 用 `TEN_DIGITS` 放行的做法）。只放行這一種形狀：`06-2019-2021` 保留，`06-2019-3456`、`06-201-2021` 仍換成 `[phone]`。
- 不在本單：「台灣」開頭接地址（例如「台灣台北市…」已被現有規則從「台北市」開始換掉，但「台灣北市…」這類）不修，見「不在本單」。

## 驗收標準
- **AC-T35-10**（NFR-04、「介面」第 1 點）`foldWidth` 只轉全形 ASCII 區段與全形空白，長度不變；`redactPii` 對全形的手機、市話、Email 照半形的規則換掉並計數；標記以外的全形字元原樣留在輸出。
