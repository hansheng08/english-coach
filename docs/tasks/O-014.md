## 介面
```ts
// tooling/usage-limit.mjs（只用 node: 內建模組）
export function detectUsageLimit(events: unknown): {
  usageLimit: boolean; resetsAt: string | null; limitType: string | null };
export function usageLimitStreak(current: boolean, previous: unknown): {
  streak: number | 'unknown'; action: 'none' | 'reschedule' | 'stop' };
export function run(argv: string[]): { code: number; stdout: string; stderr: string };
```
CLI：`node tooling/usage-limit.mjs detect --execution-file <path>`；`node tooling/usage-limit.mjs streak --current <true|false> (--previous-file <path> | --no-previous | --previous-error)`。stdout 為單行 JSON（欄位見規則），錯誤沿用其他 tooling CLI 的 `usage-limit: <RULE> …` 格式。

### 規則
- `detectUsageLimit`：`usageLimit` 為 true 的唯一條件：`events` 是陣列，且其中最後一個 `type === "result"` 的元素同時有 `is_error === true`、`api_error === "usage_limit_reached"`、`api_error_status === 429`。其他情況一律 false（不是陣列、沒有 result 元素、任一欄位不符或缺漏）。`usageLimit` 為 false 時 `resetsAt`、`limitType` 都是 null。
- `resetsAt`：取陣列中最後一個 `type === "rate_limit_event"` 且 `rate_limit_info.status === "rejected"` 的元素；其 `rate_limit_info.resetsAt` 是正的安全整數（Unix 秒）時，轉成 `YYYY-MM-DDTHH:MM:SSZ`（UTC，不含毫秒）；沒有這種元素，或值缺漏、0、負數、小數、字串、非安全整數 → null。不讀 `result` 文字。
- `limitType`：同一個元素的 `rate_limit_info.rateLimitType` 符合 `^[a-z_]{1,32}$` 時原樣回傳，否則 null。
- 任何輸入都不得丟出例外（null、數字、元素為 null 的陣列、`rate_limit_info` 不是物件）。
- `usageLimitStreak`（`previous` 是上一次同任務 run 的結果物件，或 `null`＝沒有上一次，或字串 `"error"`＝查詢失敗）：
  - `current === false` → `{ streak: 0, action: "none" }`（不看 previous）。
  - `previous === null` → `{ 1, "reschedule" }`。
  - `previous` 是物件且 `outcome` 是字串但不等於 `"usage_limit"` → `{ 1, "reschedule" }`。
  - `previous.outcome === "usage_limit"` 且 `previous.usage_limit_streak` 是正整數 n → `{ n + 1, "stop" }`。
  - 其他（`"error"`、不是物件、`outcome` 缺漏或不是字串、上一次是 usage_limit 但 streak 不是正整數或是 `"unknown"`）→ `{ "unknown", "stop" }`。
- CLI `detect`：輸出 `{"usage_limit":<bool>,"resets_at":<字串或 null>,"limit_type":<字串或 null>}`，exit 0。檔案讀不到或不是合法 JSON → `INPUT`，exit 1，stdout 不得有 JSON。
- CLI `streak`：輸出 `{"usage_limit_streak":<數字或 "unknown">,"usage_limit_action":"none"|"reschedule"|"stop"}`，exit 0。`--previous-file` 讀不到或不是合法 JSON → 視同 `"error"`（輸出 unknown／stop，exit 0）。`--current` 不是 `true`／`false`、三個 previous 選項不是恰好給一個、子命令不明、選項重複或缺值 → `USAGE`，exit 1，stdout 不得有 JSON。
