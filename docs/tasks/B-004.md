## 介面
§4.20 的 `QUESTION_CATEGORIES`、`BankQuestionSchema`、`QuestionBankBatchSchema`、QB1～QB6、migration 格式、`QUESTION_SAMPLE_SEED = 20261128` 照 ARCHITECTURE；以下是 TechLead 補的決定：
```ts
// packages/contracts/src/question.ts（新增）：上面三個匯出，index.ts 加匯出
// packages/seed-data/src/question-bank.ts（新增）
export type QuestionIssue = { readonly rule: 'QB1' | 'QB2' | 'QB3' | 'QB4' | 'QB5' | 'QB6'; readonly id: string | null; readonly message: string };
export function checkQuestionBatch(input: { readonly fileName: string; readonly data: unknown },
  others: readonly QuestionBankBatch[]): Result<QuestionBankBatch, readonly QuestionIssue[]>;
export function renderQuestionMigration(batch: QuestionBankBatch): string;
export function renderQuestionSample(batch: QuestionBankBatch): string;
```
- `checkQuestionBatch` 一次回傳**全部** issue；`data` 先過 `QuestionBankBatchSchema`，形狀不合的每個 zod issue 對應一條 QB1（`category`）或 QB2（其他欄位）。
- QB2 的「不含漢字」用 Unicode 屬性 `\p{Script=Han}`；字數用 `newsWords(text).length`。
- QB5 的正規化：轉小寫 → 把不是字母、數字、空白的字元拿掉 → 連續空白壓成一個 → trim。
- 題目內容由你產生（Q-23「AI 產生」）：英文、一般面試用語；技術題涵蓋 PRD 的兩個範圍（半導體設備系統軟體、AI 開發與應用），每個範圍至少 3 題（本批的內容要求，不寫進檢查器）；不提任何真實公司名稱或個人資料；`id` 是你寫進 JSON 的固定 UUID v4（30 個都不同；之後不改，`daily_plan.tonight_question_id` 會參照）。
- `prng.ts`：main 上沒有就由本單照 §4.10 建（`mulberry32`、`sampleWithSeed`、`seedFromString`，測試固定前 5 個輸出）；已有就重用、不改。
- migration 檔名的時間戳記用你寫單當下的 UTC 時間，必須晚於 main 上最新的 migration。

## 驗收標準
- **AC-B4-1**（§4.20 QB1、QB2）`category` 不在三類、`text` 前後有空白、少於 5 或多於 40 個字、含換行或「/」、結尾不是 `?` 或 `.`、含漢字：各自回對應規則的 issue。
- **AC-B4-2**（QB3）第 1 批少於 30 題或任一類少於 10 題回 QB3；第 2 批以後 0 題回 QB3、1 題通過。
- **AC-B4-3**（QB4、QB5）`id` 或正規化後的 `text` 在同批或與 `others` 重複時回 QB4／QB5，issue 帶重複的 `id`。
- **AC-B4-4**（QB6）`batch` 和檔名的 `<n>` 不同、或 `others` 已有同一個 `batch`：回 QB6。
- **AC-B4-5**（§4.20）多個錯誤一次全部回傳；合格的輸入回 `ok`，型別是 `QuestionBankBatch`。
- **AC-B4-6**（§4.20 migration 格式）`renderQuestionMigration` 照 §4.20 的範本：第一行註解、順序照 JSON、兩個空白縮排、`'` 寫成 `''`、最後一列以 `;` 結尾、沒有 `on conflict`、不寫 `user_id`、`resume_id`、`cited_experience`、`retired`。
- **AC-B4-7**（§4.20 抽查）`renderQuestionSample` 用 `sampleWithSeed(items, 5, 20261128)`，輸出 Markdown 表格（#、category、text）；同一批兩次輸出相同。
- **AC-B4-8**（§4.20 drift）每個 `supabase/question-bank/bank-<n>.json` 都通過 `checkQuestionBatch`，而且有逐字等於產生器輸出的 migration 與 `bank-<n>.sample.md`；反過來，有 `_b004_question_bank_<n>.sql` 或 sample 就一定有 JSON；還沒有任何批次時不失敗。
- **AC-B4-9**（Q-23、本單內容要求）`bank-1.json` 有 30 題、三類各 10 題，技術題兩個範圍各至少 3 題（由報告列出題號，TechLead 驗）。
- **AC-B4-10**（§4.10）`prng.ts` 本單建時：`mulberry32` 前 5 個輸出固定、`sampleWithSeed` 決定性且不重複、`seedFromString` 同字串同結果。
