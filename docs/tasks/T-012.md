> 名詞
> - **逐字時間戳記（`WordTiming`）**：語音轉文字時每個字的開始、結束毫秒（`startMs`、`endMs`）。
> - **停頓**：前一個字結束到下一個字開始，中間超過 2 秒（PRD AC-15）。

## 目標（一句話）
新增純函式 `computeSpeechMetrics`：依逐字稿的時間戳記算出停頓次數（> 2 秒）、贅詞次數（清單由參數傳入）、字數與每分鐘字數，失敗回 `err`、不丟例外。

## 範圍：要做（只能新增或修改這些檔案，共 4 個）
1. `packages/domain/src/speech-metrics.ts`（新增；只 import `@english-coach/contracts`）
   - `export const PAUSE_THRESHOLD_MS = 2000;`（PRD AC-15 的「> 2 秒」）
   - `export type SpeechMetrics = { readonly pauseCount: number; readonly fillerCount: number; readonly wordCount: number; readonly wpm: number };`
   - `export function computeSpeechMetrics(transcript: Transcript, fillerPhrases: readonly string[]): Result<SpeechMetrics, ValidationError>`，規則：
     1. `transcript.timing === 'none'` → `err`（`kind: 'validation'`，`issues: [{ path: 'timing', … }]`）。
     2. `transcript.durationMs <= 0` → `err`（`path: 'durationMs'`）。
     3. `words` 不是依 `startMs` 由小到大（有任何 `words[i+1].startMs < words[i].startMs`）→ `err`（`path: 'words'`）。
     4. **停頓**：相鄰兩字 `words[i+1].startMs − words[i].endMs > PAUSE_THRESHOLD_MS` 算 1 次（剛好 2000 不算；重疊為負數也不算）。第一個字之前、最後一個字之後的靜音不算。
     5. **正規化**（贅詞比對用）：轉小寫，去掉字頭字尾不是英文字母或撇號 `'` 的字元（例如 `"Um,"` → `um`）；正規化後是空字串的字不參與贅詞比對。
     6. **贅詞**：`fillerPhrases` 每一項用同樣方式正規化、以空白切成 1 個以上的字（例如 `"you know"` 是 2 個字）。從左到右掃描 `words`，在每個位置優先比對**字數最多**的贅詞，命中就 `fillerCount + 1` 並跳過那幾個字（不重疊計算）。清單是空陣列 → 0。
     7. **字數**：`wordCount = words.length`（含贅詞）。
     8. **每分鐘字數**：`wpm = wordCount ÷ (durationMs ÷ 60000)`，四捨五入到小數第 1 位（`Math.round(x * 10) / 10`）。`words` 是空陣列 → 全部為 0。
   - 一行英文註解說明「贅詞清單由呼叫端決定，domain 不放預設」。
2. `packages/domain/src/speech-metrics.test.ts`（新增）：見 AC-T12-1～3。時間戳記樣本直接寫在測試裡（固定數字），`Transcript` 用 `TranscriptSchema.parse({...})` 建立（`provider: 'groq'`、`model: 'whisper-large-v3-turbo'`、`language: 'en'`）。
3. `packages/domain/src/index.ts`（修改）：只**加** `speech-metrics.ts` 的匯出（值 `export { … }`、型別 `export type { … }`），既有的行不動。
