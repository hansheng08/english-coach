## 介面
`packages/domain/src/shadowing.ts`（v1.1 已定的簽章，本版沿用）：
```ts
export const SHADOW_MIN_ACCURACY = 0.8;
export const SHADOW_MIN_SPEED_RATIO = 0.7;
export type ShadowScore = { readonly accuracy: number; readonly speedRatio: number; readonly unlocked: boolean };
export function scoreShadowAttempt(referenceText: string, referenceDurationMs: number, result: Pick<PronunciationResult, 'recognizedText' | 'words'>): Result<ShadowScore, ValidationError>;
export function canUnlock(accuracy: number, speedRatio: number): boolean;
export function maskWords(sentence: string): readonly { readonly text: string; readonly masked: boolean }[];
```
計算照 §4.6「確認 T-011 的計算定義」與 ADR-004；以下是 v1.1 已寫明、本版沿用的細節：
- **正確率**：原句與 `recognizedText` 各自經 `normalizeWords` 得到詞序列，做詞級 Levenshtein 對齊；`accuracy`＝對齊中相同的詞數 ÷ 原句詞序列長度（多講的字不扣分）。原句詞序列為空 → `err`（`kind: 'validation'`，`issues` 含 `path` 為 `referenceText`）。
- **語速比**：`referenceDurationMs ÷ 有聲長度`，有聲長度＝`words` 最後一個的 `endMs` − 第一個的 `startMs`；可以大於 1，不截斷。`referenceDurationMs <= 0` → `err`（`path` 為 `referenceDurationMs`）；`words` 為空或有聲長度 ≤ 0 → `speedRatio` 為 0。
- **解鎖**：`unlocked`＝`canUnlock(accuracy, speedRatio)`＝正確率 ≥ 0.8 且語速比 ≥ 0.7（PRD AC-06）；發音分數（`score0to100`）不參與。
- **遮字**：以空白切 token；token 經 `normalizeWords` 後非空才算「字」；「字」從 0 起數，奇數位置 `masked: true`；不算字的 token（`/`、單獨標點）永遠 `masked: false`。n 個字遮 ⌊n/2⌋ 個，第一個字一定看得到；回傳每個 token 的原文。
- **`normalizeWords` 與 `newsWords` 的分工**（幕僚長 2026-11-25：字數一律用 contracts `newsWords`，ADR-013；`normalizeWords` 留給 T-011 的比對與遮字）：本單的正確率對齊、正確率的分母、遮字的「算不算字」都屬於**比對用的正規化**，一律用 `normalizeWords`（§4.6 寫明正確率的分母是正規化後的原句詞數）；本單沒有任何字數上下限或字數篩選，所以**不用** `newsWords`。理由：分母若改用 `newsWords`，含單獨標點（例如 `—`）的句子完全講對也會小於 1，和 AC-06「原句講對多少」矛盾。

## 驗收標準
- **AC-T11-1**（AC-06）`canUnlock` 門檻含等號：正確率剛好 0.8、語速比剛好 0.7 可以解鎖；0.799 或 0.699 不行。
- **AC-T11-2**（AC-06、ADR-004）正確率是詞級對齊後「相同詞數 ÷ 原句詞數」：完全相同為 1；漏 1 字或換 1 字各扣 1／原句詞數；多講的字不扣分；分母是原句詞數，不是辨識詞數。
- **AC-T11-3**（AC-06、§4.6）比對用 `normalizeWords`：大小寫、頭尾標點不同仍算相同；原句裡的 `/` 與單獨標點不算字（含 `—` 的原句完全講對仍是 1）。
- **AC-T11-4**（§4.6）原句沒有任何字（空字串、只有標點或 `/`）→ `err`，`path` 為 `referenceText`，不丟例外。
- **AC-T11-5**（AC-06、ADR-004）語速比只用第一個字的 `startMs` 到最後一個字的 `endMs`（去掉頭尾靜音）；大於 1 不截斷；`words` 為空 → 0；`referenceDurationMs` ≤ 0 → `err`，`path` 為 `referenceDurationMs`。
- **AC-T11-6**（AC-06、ADR-004）`scoreShadowAttempt` 的 `unlocked` 等於 `canUnlock(accuracy, speedRatio)`；結果不受 `score0to100` 影響。
- **AC-T11-7**（AC-05、§4.6）`maskWords` 遮奇數位置的字：第 2、4、6… 個字遮住，第 1 個字一定顯示；n 個字遮 ⌊n/2⌋ 個；回傳的 token 原文和順序與輸入相同。
- **AC-T11-8**（§4.6）`maskWords` 的 `/` 與單獨標點不算字、永遠不遮，也不影響後面字的奇偶位置；同一句呼叫兩次結果相同。
- **AC-T11-9**（CLAUDE.md §4）匯出：`@english-coach/domain` 匯出介面列出的 2 個常數、3 個函式與型別 `ShadowScore`。
