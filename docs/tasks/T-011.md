## 計算方式（ADR-004 ＋ TechLead 定義）
1. **正規化**：以空白切字；每個字轉小寫、去掉字頭字尾不是英文字母、數字或撇號 `'` 的字元；去掉後是空字串的（例如單獨的「/」）不算字。
2. **正確率** `accuracy`（0～1）：原句詞與辨識詞做詞級 Levenshtein 對齊，`對齊中相同的詞數 ÷ 原句詞數`。原句 0 個詞 → `err`（`kind: 'validation'`）。
3. **語速比** `speedRatio`：`referenceDurationMs ÷ 使用者有聲長度`；使用者有聲長度＝`words` 最後一個字的 `endMs − 第一個字的 startMs`（去掉頭尾靜音）。`referenceDurationMs <= 0` → `err`；`words` 為空或有聲長度為 0 → `speedRatio: 0`（不能解鎖）。
4. **解鎖**：`accuracy >= 0.8 && speedRatio >= 0.7`（PRD AC-06）；發音分數不參與。門檻寫成匯出常數 `SHADOW_MIN_ACCURACY = 0.8`、`SHADOW_MIN_SPEED_RATIO = 0.7`。
5. **遮字**：見「不確定」第 1 點。
