## 目標（一句話）

## 計算方式（ARCHITECTURE §4.6，逐條照做）
1. **正規化**：一律用 `normalizeWords`（`./words.ts`），不另寫一份。
2. **正確率** `accuracy`（0～1）：原句詞與辨識詞做詞級 Levenshtein 對齊，`對齊中相同的詞數 ÷ 原句詞數`（多講的字不扣分）。原句 0 個詞 → `err`（`kind: 'validation'`，`path: 'referenceText'`）。
3. **語速比** `speedRatio`：`referenceDurationMs ÷ 使用者有聲長度`；有聲長度＝`words` 最後一個字的 `endMs` − 第一個字的 `startMs`。`referenceDurationMs <= 0` → `err`（`path: 'referenceDurationMs'`）；`words` 為空或有聲長度 ≤ 0 → `speedRatio: 0`。可以大於 1，不截斷。
4. **解鎖**：`accuracy >= SHADOW_MIN_ACCURACY && speedRatio >= SHADOW_MIN_SPEED_RATIO`；常數 `SHADOW_MIN_ACCURACY = 0.8`、`SHADOW_MIN_SPEED_RATIO = 0.7`（PRD AC-06）。發音分數不參與。
5. **遮字**（`maskWords`）：以空白切 token；token 用 `normalizeWords(token)` 後非空才算「字」；「字」從 0 起數，**奇數位置**（第 2、4、6…個字）`masked: true`；不算字的 token（`/`、單獨標點）永遠 `masked: false`。n 個字遮 ⌊n/2⌋ 個，第一個字一定看得到。回傳每個 token 的原文與 `masked`。
