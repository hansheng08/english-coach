> 名詞
> - **SRS（間隔複習）**：答得越熟，下次出現的間隔越長。本專案的間隔天數全部由使用者設定（`settings.srs`），程式不寫死。
> - **台北日期（`PlanDate`）**：`YYYY-MM-DD` 格式、以台北時間（UTC+8）計算的日期；是品牌型別，只能由本單的 `taipei-date.ts` 或 `PlanDateSchema` 產生。
> - **性質測試**：不是只測幾個例子，而是用固定種子的亂數產生很多組合法設定，檢查「某個性質」在每一組都成立。
> - **突變測試**：故意把程式改錯，確認測試會失敗，再改回來，用來證明測試真的有在檢查。

## 範圍：要做（只能新增或修改這些檔案，共 10 個）
1. `packages/contracts/src/settings.ts`（新增；只 import `zod`）
   - `SrsSettingsSchema`：`z.object({ step_days, after_last_days, forgot_days })`，規則**完全照** ARCHITECTURE §4.2：
     - 每個天數都是**整數 1～365**（`z.number().int().min(1).max(365)`）。
     - `step_days`：剛好 3 個（`z.tuple([...])`，型別是 `[number, number, number]`），**嚴格遞增**；預設 `[3, 7, 14]`。
     - `after_last_days`：預設 `14`；必須 `≥ step_days[2]`。
     - `forgot_days`：預設 `1`；必須 `≤ step_days[0]`。
     - 預設值用 zod 的 `.default(...)` 寫在各欄位上：`SrsSettingsSchema.parse({})` 要得到 `{ step_days: [3, 7, 14], after_last_days: 14, forgot_days: 1 }`。
     - 跨欄位規則用 `.superRefine`，每個錯誤的 `path` 指到出錯的那一格（設定頁要標出哪一格錯）：不遞增 → `['step_days', i]`（`i` 是違規的那一個，1 或 2）；`after_last_days` 太小 → `['after_last_days']`；`forgot_days` 太大 → `['forgot_days']`。
   - `export type SrsSettings = z.infer<typeof SrsSettingsSchema>;`
   - 檔案開頭一行英文註解說明這個檔案放 `settings.*` 的 schema（T-049 之後會在同檔加 `NewsSettingsSchema`）。
2. `packages/contracts/src/settings.test.ts`（新增）：見 AC-T8-1、AC-T8-2。
3. `packages/contracts/src/index.ts`（修改）：最後加一行 `export * from './settings.ts';`，其他行不動。
4. `packages/domain/src/taipei-date.ts`（新增；只 import `@english-coach/contracts`）
   - `export function toTaipeiPlanDate(now: Date): Result<PlanDate, ValidationError>`：把時間點換成台北日期（固定 UTC+8，台灣沒有日光節約時間）。`now` 是無效日期（`getTime()` 是 `NaN`）時回 `err`（`kind: 'validation'`，`issues: [{ path: 'now', message: … }]`）。
   - `export function addDays(date: PlanDate, days: number): Result<PlanDate, ValidationError>`：日期加減整數天（`days` 可為 0 或負數）。`days` 不是整數、或結果超出 `0001-01-01`～`9999-12-31`，回 `err`（`path: 'days'`）。
   - `export function daysBetween(from: PlanDate, to: PlanDate): number`：回 `to − from` 的天數（整數，可為負）。
   - 實作只能用 `Date.UTC(...)`、`new Date(<數字>)`、`getUTC*()`、`getTime()`；**不得**用 `Date.now()`、無參數 `new Date()`／`Date()`、`Intl`、`toLocale*`。產生 `PlanDate` 可以用 `PlanDateSchema.safeParse` 或 `as PlanDate`（本檔是唯一允許 `as PlanDate` 的正式程式檔）。不得 `throw`；注意 `toISOString()` 遇到無效日期會丟例外，要先檢查。
5. `packages/domain/src/taipei-date.test.ts`（新增）：見 AC-T8-3。
6. `packages/domain/src/srs.ts`（新增；只 import `@english-coach/contracts`）
   - `export type SrsStep = 1 | 2 | 3 | 4;`（對應 `card.interval_step` 的 1～4；4＝第 3 階之後）
   - `export function srsIntervalDays(step: SrsStep, srs: SrsSettings): number`：1 → `step_days[0]`、2 → `step_days[1]`、3 → `step_days[2]`、4 → `after_last_days`。用 `switch`，`default` 寫 `const unreachable: never = step; return unreachable;`。

   - `export function forgotIntervalDays(srs: SrsSettings): number`：回 `forgot_days`。
   - 一行英文註解說明「猶豫＝留在同一階＝`srsIntervalDays(step)`；秒答＝`srsIntervalDays(nextSrsStep(step))`」。狀態機（Collected／Learning／Reviewing／Mastered）**不在本單**，是 T-009。
