## 驗證方式（每個指令單獨執行，完整輸出貼進報告）
| # | 指令 | 預期 |
|---|---|---|
| 1 | `pnpm install --frozen-lockfile`（開始改之前跑一次） | exit 0 |
| 2 | `pnpm check`（開始改之前跑一次，作為基準） | exit 0 |
| 3 | `pnpm test`（改完後） | 全部 pass；`packages/domain/src/package-info.test.ts` 有 1 個以上測試通過 |
| 4 | 突變測試：改值 → `pnpm test` → 改回 | 改值時 `package-info.test.ts` FAIL（完整貼上）；改回後全過 |
| 5 | `pnpm check`（改完、還原後） | exit 0 |
| 6 | `git diff --name-only origin/main...HEAD`（commit 之後） | 只有「範圍：要做」的 4 個檔案 |
| 7 | `git status --short`（push 之前） | 無輸出 |

（任何指令被權限規則擋下時，不要換別的寫法，把被擋的指令與訊息完整貼進報告，寫「未執行」和原因。）
