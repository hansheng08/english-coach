## 介面
TechLead 決定（檔名與名稱照此）：
```ts
// apps/web/src/features/resume/redact.ts（純函式，不讀時鐘、不連網、不碰 DOM）
export type PiiCounts = { readonly phone: number; readonly email: number; readonly address: number };
export function redactPii(text: string): { readonly text: string; readonly removed: PiiCounts };
// apps/web/src/features/resume/extract.ts
export type ResumeFile = { readonly name: string; readonly type: string; readonly bytes: Uint8Array };
export type PdfTextItem = { readonly str: string; readonly hasEOL: boolean };
export type ExtractDeps = {
  readonly pdfPages: (bytes: Uint8Array) => Promise<readonly (readonly PdfTextItem[])[]>;
  readonly docxRawText: (bytes: Uint8Array) => Promise<string>;
};
export const defaultExtractDeps: ExtractDeps; // 內部用動態 import() 載入 pdfjs-dist、mammoth
export function extractResumeText(file: ResumeFile, deps?: ExtractDeps): Promise<Result<string, ValidationError>>;
```
**標記與順序**：Email → `[email]`，電話 → `[phone]`，地址 → `[address]`。先處理 Email，再電話，最後地址。標記以外的文字（含空白、換行、標點）一個字元都不變。
- 冪等：對結果再跑一次，文字不變、`removed` 全是 0。

**Email**
- 形式：`local@domain`。
  - `local` 由英數字與 `. _ % + -` 組成，至少 1 個字元。
  - `domain` 是 2 段以上、以 `.` 連接的英數字或 `-` 段落，最後一段至少 2 個字母。
- 比對不分大小寫。結尾緊接的句點不屬於 Email（`a@example.com.` 只換到 `com`）。

**電話**
- 共通規則：
  - 分隔符是一個空白、`-` 或 `.`，同一個號碼內可以混用。
  - 號碼前後緊鄰的字元不能是英文字母或數字。
  - 前置的 `+`、括號都算在號碼內。
- 台灣手機：
  - 開頭是 `09`，或國碼（`+886`、`(+886)`、`886`，後面可以有 1 個分隔符）接 `9`。
  - 之後共 8 位數字，以 `9dd`／`09dd`、`ddd`、`ddd` 分組，組間可以有 0～1 個分隔符。
- 台灣市話：
  - 開頭是區碼：`0` 加 1～2 位數字（第一位 2～8），可以用括號包（`(02)`）；或國碼（同手機，後面可以有 1 個分隔符）接不含 `0` 的區碼。
  - 之後 6～8 位數字，中間最多 1 個分隔符；區碼與號碼之間可以有 0～1 個分隔符。
  - 沒有區碼的 7～8 位號碼**不算**，避免誤刪年份區間（例如 `2019-2023`）。
- 美國：
  - 可選國碼 `+1` 或 `1`，後面接 0～1 個分隔符。
  - 區碼 3 位（第一位 2～9，可以用括號包）、局碼 3 位（第一位 2～9）、4 位，組間可以有 0～1 個分隔符。
  - 整串 10 位數字連在一起、又沒有 `+1` 時**不算**，避免誤刪編號。

**地址**（只認街道層級，要有門牌；只有城市、州或國家的不算，例如 `Taipei, Taiwan`、`San Jose, CA`）
- 美國：
  - 門牌 1～6 位數字＋1～4 個字＋街道類型字（`St`、`Street`、`Ave`、`Avenue`、`Rd`、`Road`、`Blvd`、`Boulevard`、`Dr`、`Drive`、`Ln`、`Lane`、`Way`、`Ct`、`Court`、`Pl`、`Place`、`Pkwy`、`Parkway`、`Hwy`、`Highway`，可帶 `.`，不分大小寫）。
  - 之後同一行可以接（以 `,` 或空白隔開）：單位（`Apt`、`Suite`、`Ste`、`Unit`、`#` 加英數字）；`, 城市, 州`，城市是 1～3 個首字大寫的字，州是 2 個大寫字母，後面接 5 位或 5-4 位郵遞區號。
  - 整段換成一個 `[address]`。
- 台灣（英文）：
  - 從 `No.`＋數字（可以是 `數字-數字`）開始；前面緊鄰的 `數字F.,`／`數字F,`（樓層）也算進去。
  - 同一行往後以 `,` 分開的每一段，只要含 `Rd.`、`Road`、`St.`、`Street`、`Ave.`、`Avenue`、`Sec.`、`Section`、`Ln.`、`Lane`、`Aly.`、`Alley`、`Dist.`、`District`、`Vil.`、`Village`、`City`、`County`、`Township` 之一，或是 3～6 位郵遞區號、`Taiwan`、`Taiwan (R.O.C.)`、`R.O.C.`，就算進地址；遇到第一段不符合的就停。
  - `No.` 後面至少要有一段符合，才算地址（`No. 1 in sales` 不算）。
- 中文：
  - 開頭可以有 3～6 位郵遞區號；接著是一段連續漢字與數字，含 `市` 或 `縣`、含 `路`／`街`／`大道`／`巷`／`弄` 之一，並以 `號` 結尾。
  - 結尾後緊接的 `數字樓`、`之數字`、`-數字` 也算進去。

**`extractResumeText`**
- 類型判斷（不分大小寫）：副檔名 `.pdf` 或 MIME `application/pdf` → PDF；副檔名 `.docx` 或 MIME `application/vnd.openxmlformats-officedocument.wordprocessingml.document` → DOCX。其他（含 `.doc`）→ `err` `validation`，`issues: [{ path: 'file', message: 'unsupported file type' }]`。
- PDF 文字組法：依頁序，每頁把 `str` 依序接起來，`hasEOL` 為 true 的項目後面加 `\n`；頁與頁之間加 `\n`。
- DOCX：用 `docxRawText` 的結果，不另外整理。
- `deps` 丟出例外 → `err` `validation`（`path: 'file'`、`message: 'cannot read file'`），不往外丟。去頭尾空白後是空字串（例如只有圖片的 PDF）→ `err` `validation`（`path: 'file'`、`message: 'no text found'`）。
- 成功時回轉出的文字，**不做**去個資（呼叫端再呼叫 `redactPii`，T-036 決定流程）。
- `defaultExtractDeps`：
  - 只在函式被呼叫時，用動態 `import()` 載入 `pdfjs-dist` 與 `mammoth`。
  - pdf.js 的 worker 用 Vite 的 `?url` 匯入取得網址，設定給 `GlobalWorkerOptions.workerSrc`；實際路徑以安裝版本的套件內容為準。
  - DOCX 用 `mammoth.extractRawText`。
  - 不改 Vite 與 PWA 設定。
- **依賴**：`apps/web/package.json` 的 `dependencies` 只加 `pdfjs-dist`（`^6`）與 `mammoth`（`^1`）。之後單獨執行一條 `pnpm install --no-frozen-lockfile` 更新 `pnpm-lock.yaml`。

- **QA 擁有的檔案不碰**：不得新增、修改、刪除或改名任何 `**/*.qa.test.ts` 與 `docs/qa/` 下的檔案。`docs/qa/**` 不列進「範圍外」：scope-check 先比對範圍外，列進去會讓 QA 自己的 commit 被判違規。既有的 QA 探針要照樣通過。
- 既有測試（T-018、T-019、T-052，含 `project-rules.test.ts`）不刪、不改，要照樣通過。

## 不在本單
- 履歷頁、上傳、進度、去個資預覽與刪除（T-036；頁面還沒有設計）。
- 實際用 `pdfjs-dist`／`mammoth` 轉真的 PDF、DOCX，以及 worker 在瀏覽器裡載入：本單沒有頁面可以跑 E2E，留給 T-036 的 PR e2e（上傳 PDF 與 DOCX）驗證。本單的建置只由 PR CI 的 `bundle` job 驗證。
- 姓名、LinkedIn 等網址、身分證字號：NFR-04 只列電話、Email、地址，本單不移除。

## 驗證方式
`pnpm check` 跑到通過；任務單不另列指令。run-task 不能跑 `pnpm build`，打包（動態載入、worker 網址）由 PR CI 的 `bundle` job 驗證；報告照實寫「沒有在本機建置」。

## 結束時
1. 在指定的分支上 commit 並 push，不得動 main。
2. 把結果寫到 docs/reports/T-035.md：完成摘要、變更檔案、測試結果、未完成事項、需要人類決定的問題。
3. 測試結果、突變結果、權限被拒以 workflow 自動產生的摘要與 PR 觸發的 CI run 為準，報告不重貼。
