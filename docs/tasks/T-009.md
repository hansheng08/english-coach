> - **狀態機**：卡片只能依固定規則在 Collected／Learning／Reviewing／Mastered 之間轉換，不合法的轉換寫不出來或回 `err`。

## 範圍：要做（只能新增或修改這些檔案，共 7 個）
1. `packages/contracts/src/card.ts`（新增；只 import `zod` 與 `./ids.ts`）：**逐字照** ARCHITECTURE §4.3 的程式碼區塊（`CARD_STATES`／`CardStateSchema`／`CardState`、`REVIEW_RATINGS`／`ReviewRatingSchema`／`ReviewRating`、`REVIEW_MODES`／`ReviewModeSchema`／`ReviewMode`、`CARD_SOURCE_TYPES`／`CardSourceTypeSchema`／`CardSourceType`、`IntervalStepSchema`／`IntervalStep`、`CardScheduleSchema`／`CardSchedule`、`ReviewRequestSchema`／`ReviewRequest`）。不另加欄位或型別。
2. `packages/contracts/src/card.test.ts`（新增）：見 AC-T9-1。
3. `packages/contracts/src/index.ts`（修改）：最後加一行 `export * from './card.ts';`，其他行不動。
4. `packages/domain/src/card-state.ts`（新增；只 import `@english-coach/contracts` 與 `./srs.ts`、`./taipei-date.ts`）：
   - `export type ReviewOutcome = { readonly before: CardState; readonly schedule: CardSchedule; readonly intervalDaysApplied: number };`
   - `export function applyReview(card: CardSchedule, rating: ReviewRating, today: PlanDate, srs: SrsSettings): Result<ReviewOutcome, ValidationError>`：照 §4.3 轉換表（到期日＝`addDays(today, d)`；`addDays` 回 `err` 時原樣回傳 `err`；`correctCount` 只增不減；回到 Reviewing 從第 1 階；mastered → `err`，`kind: 'validation'`、`issues` 有 `path: 'state'`）。外層 `switch (card.state)`、內層 `switch (rating)` 都要 `never` 窮舉。
   - `export function markMastered(card: CardSchedule): { readonly schedule: CardSchedule; readonly changed: boolean }`：只有 reviewing → mastered（`intervalStep` 保留、`dueDate: null`、`correctCount` 不變、`changed: true`）；其他狀態原樣回傳、`changed: false`。
   - domain 的 `SrsStep`（T-008）與 contracts 的 Reviewing 階段（1～4）是同一組值；需要轉換時用 `switch` 或型別縮小，不用 `as`。
5. `packages/domain/src/card-state.test.ts`（新增）：見 AC-T9-2～4。
6. `packages/domain/src/index.ts`（修改；只**加** `card-state.ts` 的匯出）
7. `docs/reports/T-009.md`（新增）

## 實作限制（共通）
- 相對 import 一律寫 `.ts` 副檔名；跨套件只寫 `@english-coach/contracts`（測試可加 `@english-coach/contracts/testing` 的 `expectOk`／`expectErr`）。contracts 正式程式只 import `zod` 與 ARCHITECTURE §5.0.1 允許的下層檔案。
- domain 測試只能 import `vitest`、`@english-coach/contracts`、`@english-coach/contracts/testing`、domain 自己的檔案（含 `../test/prng.ts`）。測試裡的 `PlanDate`、`CardId` 等用 schema 的 `.parse(...)` 建立。
- 不用 `eslint-disable`、`@ts-ignore`、`any`、`as unknown as`、非空斷言 `!`；品牌型別不得 `as`（只有 `taipei-date.ts` 可以 `as PlanDate`，本單不需要）。domain 正式程式不 `throw`、不讀時鐘、不用 `Math.random`、不用 `Intl`／`localeCompare`（字串比較用 `<`／`>`，結果才可重現）。
- `switch` 的 `default` 一律 `const unreachable: never = x; return unreachable;`。
- `it.skip`、`it.only`、`describe.only` 不得提交。突變測試用 Edit 工具改、跑、改回；不要用 `git checkout`、`git restore`、`git stash`、`cp`。
