## 範圍：要做（只能新增或修改這些檔案，共 7 個）
1. `packages/contracts/src/card.ts`（修改；只**加**，既有內容不動）：
   - `export const ChunkTextSchema = z.string()...`：§4.7「chunk 文字格式」——頭尾沒有空白；以**單一空白**分隔的 1 個以上的字；每個字只含英文字母、撇號 `'`、連字號 `-`，且至少有 1 個字母；不含括號、斜線、`…`、數字、其他標點。
2. `packages/contracts/src/card.test.ts`（修改；只**加** `ChunkTextSchema` 的 `describe`）
3. `packages/domain/src/irregular-verbs.ts`（新增；不 import 任何東西）：`export const IRREGULAR_VERB_FORMS: ReadonlyMap<string, readonly string[]>`——原形 → 過去式與過去分詞（去重），**至少 90 個**常見不規則動詞（**TechLead 決定**（幕僚長 2026-11-23 裁定：實作層級的選擇，由 TechLead 決定，不需 Architect 確認）：ARCHITECTURE §4.7 只說「約 100 個」，清單內容由 Claude Code 撰寫，下面列的是一定要有的），一定要有：`be`（`am`、`is`、`are`、`was`、`were`、`been`、`being`）、`have`、`do`、`go`、`take`、`make`、`get`、`give`、`come`、`see`、`know`、`think`、`say`、`tell`、`find`、`bring`、`buy`、`build`、`write`、`run`、`lead`、`keep`、`hold`、`set`、`put`、`break`、`choose`、`drive`、`speak`、`understand`、`begin`、`fall`、`feel`、`grow`、`leave`、`lose`、`meet`、`pay`、`send`、`spend`、`stand`、`teach`、`win`。
4. `packages/domain/src/chunk-hit.ts`（新增；只 import `@english-coach/contracts` 與 `./irregular-verbs.ts`）
   - `export type ChunkHitLevel = 'full' | 'partial' | 'none';`
   - `export type ChunkHit = { readonly target: string; readonly level: ChunkHitLevel; readonly matchedText: string | null };`（`matchedText`＝命中範圍的正規化字以空白連接；`none` 時為 `null`）
   - `export function detectChunkHits(transcriptText: string, targets: readonly string[]): readonly ChunkHit[]`（回傳順序同 `targets`）
   - `export function scoreChunkHits(hits: readonly ChunkHit[]): number`（＝`full` 的個數）
   - 規則**逐條照** §4.7：
     - 正規化（逐字稿與 chunk 都做）：轉小寫；連字號換成空白；去掉每個字頭尾的標點；以空白切字；整字比對。
     - 佔位詞：`sb`、`someone`、`somebody`、`sth`、`something` 比對 1～4 個任意字；`one's`、`sb's`、`someone's` 比對 1 個所有格字（`my`、`your`、`his`、`her`、`its`、`our`、`their`，或以 `'s` 結尾的字）。
     - 詞形：chunk 的非佔位詞 `w` 與逐字稿的字 `t` 符合任一即相同：`t = w`；`w+s`；`w+es`；子音＋`y` 結尾 → `ies`／`ied`；`w+ed`；`w+d`；`w+ing`；去 `e` 加 `ing`；重複字尾子音＋`ed`／`ing`；`IRREGULAR_VERB_FORMS.get(w)` 裡的形。
     - `full`：所有非佔位詞依序、連續出現（佔位詞位置可夾 1～4 個字或 1 個所有格字）。
     - `partial`：不是 `full`，chunk 有 ≥ 2 個非佔位詞，且逐字稿中有一段長度 ≤（非佔位詞數＋2）的範圍，依序出現其中 ≥ ⌈非佔位詞數 ÷ 2⌉ 個。單字 chunk 只有 `full`／`none`。
     - chunk 正規化後沒有任何非佔位詞 → `none`。

6. `packages/domain/src/index.ts`（修改；只**加**匯出）
