## 介面
```ts
// packages/contracts/src/card.ts（只加）
export const ChunkTextSchema: z.ZodType<string>;
// packages/domain/src/irregular-verbs.ts（新增；不 import 任何東西）
export const IRREGULAR_VERB_FORMS: ReadonlyMap<string, readonly string[]>; // 原形 → 過去式與過去分詞（去重）
// packages/domain/src/chunk-hit.ts（新增；只 import @english-coach/contracts、./words.ts、./irregular-verbs.ts）
export type ChunkHitLevel = 'full' | 'partial' | 'none';
export type ChunkHit = { readonly target: string; readonly level: ChunkHitLevel; readonly matchedText: string | null };
export function detectChunkHits(transcriptText: string, targets: readonly string[]): readonly ChunkHit[];
export function scoreChunkHits(hits: readonly ChunkHit[]): number;
```
- **`ChunkTextSchema`**（§4.7 格式）：頭尾沒有空白；以單一空白（U+0020）分隔的 1 個以上的字；每個字只含英文字母、直撇號 `'`、連字號 `-`，且至少 1 個字母。不含括號、斜線、`…`、數字、彎引號、其他標點、tab、換行。§11.3.3 C2 合格的 chunk 一定也通過。
- **TechLead 決定**（v1.2 沿用，幕僚長 2026-11-23 裁定實作層級的選擇由 TechLead 決定）：schema 名稱 `ChunkTextSchema`、放 `card.ts`；T-024 的 `SeedChunkSchema` 與 AI 產生字卡之後都用它。`IRREGULAR_VERB_FORMS` 至少 90 個常見不規則動詞（§4.7「約 100 個」），清單由你撰寫，一定要有：`be`（`am`、`is`、`are`、`was`、`were`、`been`、`being`）、`have`、`do`、`go`、`take`、`make`、`get`、`give`、`come`、`see`、`know`、`think`、`say`、`tell`、`find`、`bring`、`buy`、`build`、`write`、`run`、`lead`、`keep`、`hold`、`set`、`put`、`break`、`choose`、`drive`、`speak`、`understand`、`begin`、`fall`、`feel`、`grow`、`leave`、`lose`、`meet`、`pay`、`send`、`spend`、`stand`、`teach`、`win`。
- **正規化**（逐字稿與 chunk 都做；§4.7）：先把 `‘`、`’` 換成 `'`，再把 `-` 換成空白，然後交給 `normalizeWords`（轉小寫、以空白切字、去掉每個字頭尾 a–z、0–9、`'` 以外的字元、丟掉空字）。比對以整個字為單位。**TechLead 決定**：「頭尾標點」沿用 T-010 `normalizeWords` 的定義，不另寫一份；彎引號比照 T-023 換成直引號（STT 可能輸出 `Tom’s`）。
- **不用 `newsWords`**：ADR-013 的 `newsWords` 管文字的字數上下限（250～300、6～25、2～6）；本單沒有字數上下限，「非佔位詞數」「範圍長度」都是正規化後比對序列裡的位置，用 `newsWords` 會把單獨標點算進範圍卻永遠比不到。
- **佔位詞**（只看 chunk 裡的字）：`sb`、`someone`、`somebody`、`sth`、`something` 比對連續 1～4 個任意字；`one's`、`sb's`、`someone's` 比對 1 個所有格字（`my`、`your`、`his`、`her`、`its`、`our`、`their`，或以 `'s` 結尾的字）。
- **詞形**：chunk 的非佔位詞 `w` 與逐字稿的字 `t` 符合任一即相同：`t = w`；`w+s`；`w+es`；子音＋`y` 結尾 → `ies`／`ied`；`w+ed`；`w+d`；`w+ing`；去 `e` 加 `ing`；重複字尾子音＋`ed`／`ing`；`IRREGULAR_VERB_FORMS.get(w)` 裡的形。對所有詞都套用。
- **等級**：`full`＝所有非佔位詞依序、連續出現（佔位詞位置夾 1～4 個字或 1 個所有格字）；`partial`＝不是 `full`、非佔位詞數 n ≥ 2，且有一段長度 ≤ n＋2 個字的範圍依序出現其中 ≥ ⌈n ÷ 2⌉ 個；其他 `none`。n ＝ 1 只有 `full`／`none`；n ＝ 0（例如 `sb`、空字串）→ `none`。
- **`matchedText`**（**TechLead 決定**：只給畫面用，不影響等級與分數）：`none` → `null`。`full` 取起點最左的命中，每個佔位詞取能成立的最少字數（句尾佔位詞取 1 個字），值＝命中範圍（含佔位詞的字）的正規化字以單一空白連接。`partial` 取起點最左、再取最短的合格範圍，值＝從第一個到最後一個對到的非佔位詞。
- **計分**：`scoreChunkHits` ＝ `full` 的個數；`partial` 0 分。回傳陣列順序與 `targets` 相同；重複的 target 各自判斷；`targets` 為空 → `[]`；逐字稿為空 → 全部 `none`。函式不丟例外、不改輸入。

## 驗收標準
- **AC-T13-1**（§4.7 格式）`ChunkTextSchema` 通過合格格式（含佔位詞與單字 chunk），擋下括號、斜線、`…`、數字、彎引號、頭尾或連續空白、tab、沒有字母的字、空字串。
- **AC-T13-2**（§11.3.3 C2）C2 合格的新聞 chunk 都通過 `ChunkTextSchema`。
- **AC-T13-3**（AC-18、§4.7）正規化：大小寫、頭尾標點不同仍 `full`；`buy-in` 與 `buy in` 雙向互相命中；彎引號的所有格可對到佔位詞。
- **AC-T13-4**（AC-18）整字比對：字的一部分不算命中。
- **AC-T13-5**（AC-18、§4.7）規則詞形每一種各至少一筆會命中；不在規則內的衍生字不命中。
- **AC-T13-6**（AC-18、§4.7）不規則形：`take`→`took`／`taken`、`be`→`was`、`lead`→`led` 命中；`IRREGULAR_VERB_FORMS` 至少 90 個原形且含必列清單。
- **AC-T13-7**（AC-18、§4.7）佔位詞：一般佔位詞可夾 1～4 個字、5 個字就不是 `full`、句尾佔位詞後面要至少 1 個字；所有格佔位詞只對 1 個所有格字。
- **AC-T13-8**（AC-18、§4.7）部分命中門檻：範圍 ≤ n＋2、依序 ≥ ⌈n ÷ 2⌉ 個；n ＝ 1 不會 `partial`；n ＝ 0 → `none`。
- **AC-T13-9**（AC-18、M4、ADR-011 決定 5）計分＝`full` 個數，`partial` 不加分；順序與 `targets` 相同；空輸入照「介面」。
- **AC-T13-10**（介面）`matchedText` 照「介面」的規則。
- **AC-T13-11**（CLAUDE.md §4）匯出：`@english-coach/domain` 匯出 `detectChunkHits`、`scoreChunkHits` 與型別 `ChunkHit`、`ChunkHitLevel`；`@english-coach/contracts` 可 import `ChunkTextSchema`。
