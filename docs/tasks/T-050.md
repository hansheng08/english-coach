## 介面
`prng.ts`（`packages/domain/src/prng.ts`；正式程式不用 `Math.random`、`Date.now`、`throw`）與 `seed-chunks.ts` 的新增匯出：
```ts
export function mulberry32(seed: number): () => number;                       // 公開的 mulberry32；seed 先 >>> 0；回 [0, 1)
export function sampleWithSeed<T>(items: readonly T[], n: number, seed: number): T[];
export function seedFromString(s: string): number;                            // FNV-1a 32 位元，輸入字串轉 UTF-8 位元組，回 0～4294967295 的整數
// packages/seed-data/src/seed-chunks.ts（只新增，既有函式與常數不改）
export const SEED_SAMPLE_SEED = 20261127;   // 固定，不可改
export const SEED_SAMPLE_SIZE = 20;
export function renderSeedSample(batch: SeedBatch): string;
```
- `mulberry32` 的演算法和 `packages/domain/test/prng.ts` 相同（同一個種子，輸出的數字完全一樣）。
- `sampleWithSeed`：部分 Fisher–Yates。複製一份陣列；對 i＝0 到 k－1（k＝min(n, 長度)）：用 `mulberry32(seed)` 的下一個數 r，取 j＝i＋floor(r × (長度－i))，交換位置 i 與 j；回傳前 k 個。不修改傳入的陣列；n 小於等於 0 回空陣列；n 大於長度時等於 k＝長度。
- `renderSeedSample` 是純函式，只做格式化、不驗證：取 `sampleWithSeed(batch.items, SEED_SAMPLE_SIZE, SEED_SAMPLE_SEED)`，輸出 Markdown，格式如下（`#` 是 1 起算的抽樣順序；`tags` 用 `, ` 接起來，沒有標籤寫 `-`；儲存格內的 `|` 寫成 `\|`；全文結尾一個換行）：
```
# T-050 seed_chunk batch <n> sample (SEED_SAMPLE_SEED 20261127, <k> of <items 筆數>; source supabase/seed-chunks/batch-<n>.json)

| # | chunk | meaning_zh | example_en | tags |
|---|---|---|---|---|
| 1 | take over | 接手 | I can take over the demo next week. | meeting, project |
| 2 | get buy-in from sb | 取得某人的支持 | We need to get buy-in from the whole team. | - |
```
- 兩個常數是 ARCHITECTURE §4.10 已定的值，不是待決事項；`index.ts` 已經 `export *`，不用改。

## 驗收標準
- **AC-T50-1**（§4.10 `mulberry32`）同一個種子輸出的序列相同；1,000 次輸出都在 0 以上、小於 1；種子 1 與 20261127 的前 5 個輸出寫死在測試裡，並且等於 `packages/domain/test/prng.ts` 的輸出。
- **AC-T50-2**（§4.10 `sampleWithSeed`）結果的每一項都來自 `items`、互不相同、順序等於上面「介面」的演算法（測試內用 `../test/prng.ts` 另寫一份對照）；同樣的輸入兩次相同；不修改輸入；n 為 0 回空、n 大於長度回全部。
- **AC-T50-3**（§4.10 `seedFromString`）空字串、`a`、`foobar` 依序是 2166136261、3826002220、3214735720（FNV-1a 32 位元的公開測試值）；中文字串用 UTF-8 位元組；同一個字串結果相同、`a` 與 `b` 不同；結果是 0 以上、小於 2 的 32 次方的整數。
- **AC-T50-4**（§4.10 抽查樣本）`SEED_SAMPLE_SEED` 是 20261127、`SEED_SAMPLE_SIZE` 是 20，兩者與 `renderSeedSample` 都從 `@english-coach/seed-data` 匯出，`prng` 三個函式都從 `@english-coach/domain` 匯出；`renderSeedSample` 的輸出符合「介面」的格式、取樣等於 `sampleWithSeed(items, 20, 20261127)` 的順序、同樣輸入兩次相同、不修改輸入、空標籤寫 `-`、`|` 被跳脫。
- **AC-T50-5**（§4.10 樣本 drift）比對函式在「JSON、migration、樣本」三張檔名對內容的表上：`batch-1.json` 有、樣本檔沒有 → 失敗；樣本檔和 `renderSeedSample` 的輸出不同 → 失敗；樣本檔沒有對應的 JSON → 失敗；一致 → 通過；其他批的樣本檔有就同樣比對、沒有不算失敗。
- **AC-T50-6**（§4.10 drift，實際目錄）`supabase/seed-chunks/` 裡每個 `batch-<n>.json` 經 `checkSeedBatch`（`fileName` 為 basename，`others` 為其他批）回 `ok`；`supabase/migrations/` 剛好有一個以 `_seed_chunk_batch_<n>.sql` 結尾的檔，內容逐字等於 `renderSeedMigration`；`batch-1.json` 在就必須有 `batch-1.sample.md` 且逐字等於 `renderSeedSample`；`example_en` 在所有批次之間（正規化大小寫與頭尾空白後）不重複。
- **AC-T50-7**（品質檢查）每個已存在的批次，`SEED_TAGS` 的 8 個標籤每個至少出現 5 次；全部 `meaning_zh` 都至少有 1 個漢字（R2 已檢查，這裡只防空批）。
- **AC-T50-8**（完整性，條件式）已存在的批次號必須是 1 到 m 連續、沒有缺號；只有 `batch-6.json` 存在時才要求 6 批齊全，而且全部 `chunk` 共 600 條、正規化後互不相同。
