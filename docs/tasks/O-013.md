### 規則
- `baseTaskId`：符合 `^[TQOAP]-\d{3}$` 原樣回傳；符合 `^([TQOAP]-\d{3})-fix[1-9]\d*$` 回傳括號部分；其他（`T-15-fix1`、`T-015-fix`、`T-015-fix0`、`T-015-fix1-fix2`、空字串）回傳 null。
- verify-summary：沒給 `--mutants` 時印 `未執行（沒有 <mutantsPathFor(task)>）`；`--task` 的 `baseTaskId` 為 null → `USAGE` exit 1。摘要標題仍用原本的 `--task`。
- scope-check 的突變檔：`docs/qa/mutants/*.json` 是 QA 擁有檔（擁有者檢查與 O-012 相同），但允許範圍仍限定編號：只允許「本分支每張任務單的編號與其 `baseTaskId`」以及 `branchId(branch)` 的 `.json`，其他編號 → `SC-OUT`。`isQaTestFile` 為 true 的檔才在 `SC-DENY`／`SC-OUT` 之前一律允許（同 O-012）。
- 變更清單含突變檔但沒給 `--commits` → `SC-QA-NOLOG`（同 O-012 規則）。既有測試若因此改變結果，改成附上 `[QA]` commit 清單，期望值不變。
