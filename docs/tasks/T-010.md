> ## 📌 本單特別規則（和上面 10 條同樣強制）
> 11. **原始輸出不得刪列、不得節錄**：「驗證方式」每一個指令都要**單獨執行**，把輸出**完整**貼進報告（不得只貼最後幾行、不得用「…」省略、不得改寫）。輸出很長時可以用 `<details>` 折疊，但內容不得刪減。本單不適用憲章 §13「最後 20 行以內」的上限。

> 13. **無人值守**：本單在 GitHub Actions 上執行，沒有人能回答問題。任務單不清楚、和架構文件矛盾、或指令被權限規則擋下時：不要猜、不要繞路、不要換別的寫法，把狀況（被擋的指令與完整訊息）寫進報告的「需要人類決定的問題」，commit 並 push 已完成的部分與報告後結束。
> 14. **不新增依賴**：不改任何 `package.json`、`pnpm-lock.yaml`、`pnpm-workspace.yaml`；只能用 `pnpm install --frozen-lockfile`。如果真的需要新依賴，停下寫報告。
> 15. **只用允許的指令**：Bash 只用 `git …`（不含 `git merge*`、`git checkout`、`git restore`、`git stash`、`git reset`）、`pnpm install --frozen-lockfile`、`pnpm check`、`pnpm typecheck`、`pnpm lint`、`pnpm arch`、`pnpm test`；檔案用 Read／Write／Edit／Glob／Grep 工具。不用 `gh`、`curl`、`rg`、`npx`、`node`、`cp`、`rm`、`sed`。
