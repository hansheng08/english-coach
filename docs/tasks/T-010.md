   - **選卡**（§4.4）
     ```ts
     export type CardCandidate = { readonly cardId: CardId; readonly schedule: CardSchedule; readonly priorityNew: boolean; readonly createdAtMs: number };
     export type SeedCandidate = { readonly seedChunkId: string; readonly batch: number };
     export type DailyCardSelection = {
       readonly oldCardIds: readonly CardId[];      // 到期舊卡前 15 張（依排序）
       readonly newCardIds: readonly CardId[];      // 新卡（依排序）
       readonly seedChunkIds: readonly string[];    // 種子補位（依排序）
       readonly extraOldCardIds: readonly CardId[]; // 新卡＋種子仍不足時，從到期舊卡第 16 張起補
       readonly total: number;                      // 四者合計，≤ 25
     };
     export function selectDailyCards(input: { readonly cards: readonly CardCandidate[]; readonly seeds: readonly SeedCandidate[]; readonly usedSeedChunkIds: ReadonlySet<string> }, today: PlanDate): DailyCardSelection;
     ```
     - 到期舊卡：`state ∈ {collected, learning, reviewing}`、`dueDate ≠ null`、`dueDate ≤ today`；mastered 與還沒到期的忽略。排序：`dueDate` 早 → `intervalStep` 小 → `createdAtMs` 小 → `cardId`（字串 `<`）。
     - 新卡：`state = collected` 且 `dueDate = null`。排序：`priorityNew = true` 優先 → `createdAtMs` 小 → `cardId`。
     - 種子：`seedChunkId` 不在 `usedSeedChunkIds` 的才算；排序：`batch` 小 → `seedChunkId`（字串 `<`）。
     - 數量：`o = min(15, 到期舊卡數)`；新卡＋種子合計最多 `25 − o`（先新卡、再種子）；還不足時從到期舊卡第 16 張起依排序補到 25 或用完；全部用完時 `total < 25`。

     ```ts
     export type QuestionCandidate = { readonly questionId: QuestionId; readonly source: 'resume' | 'bank'; readonly category: 'intro' | 'behavioral' | 'technical'; readonly retired: boolean; readonly timesAsked: number; readonly lastAskedDate: PlanDate | null };
     export function selectTonightQuestion(candidates: readonly QuestionCandidate[]): QuestionId | null;
     ```
     - 只看 `retired = false`；有任何 `source = 'resume'` 時只從履歷題選，否則從 `bank` 選；排序：`timesAsked` 少 → `lastAskedDate` 早（`null`＝沒問過，排最前）→ `category` 依 `intro → behavioral → technical` → `questionId`。沒有候選回 `null`。

   - **晚上提示 chunk**（§4.5）

     export type ReviewedTodayCard = { readonly cardId: CardId; readonly chunk: string; readonly state: CardState; readonly intervalStep: IntervalStep; readonly reviewedAtMs: number };
     export type ReviewingFallbackCard = { readonly cardId: CardId; readonly chunk: string; readonly intervalStep: IntervalStep; readonly lastReviewedDate: PlanDate };

     export type ShadowSentenceCandidate = { readonly text: string; readonly containsTargetChunk: boolean };  // 呼叫端依 news_article.chunks 的「所在句」或升級語塊標記
