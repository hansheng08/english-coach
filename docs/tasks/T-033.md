## 目標
中午打開複習頁，依序複習今天的卡：每張依 `selectNoonMode` 出模式 B、模式 A 選項題或模式 A 自行回想，作答後自評「秒答／猶豫／忘記」並送 `POST /reviews`；全部答完送中午 `completed`。不出聲、不載入錄音模組。


- **`ReadyPlan`**：本單在 `features/noon/session.ts` 內定義，等於 `DailyPlan` 中 `status` 為 `ready` 的那一種（`@english-coach/contracts` 沒有這個名字，不要加進 contracts）。
- **頁面**：路由 `/noon`（`RequireSession`）。打開時 `planToday` → 不是 `ready` 時照 `screens/prep.md`（T-026 的元件，main 上還沒有就顯示 §5.0.4 的錯誤卡＋「重試」）。`ready` → `listCards(cardIds)`、`listReviewedCardIds(planDate)`、`getSrsSettings` → `buildNoonSession` 照 `card_ids` 的順序、跳過今天已評過的卡；`selectNoonMode` 回 `postpone` 的卡不會在 `card_ids` 裡（§4.14.5），出現了就跳過並寫 log。
- **送打卡**：打開頁面送 `{slot:'noon', step:'slot', status:'opened'}`；最後一張評完（或 `card_ids` 是 0 張）送 `{slot:'noon', step:'cards', status:'completed'}`；0 張時兩個都在打開時送。打卡失敗不擋作答，只在頁面底部顯示一行 §5.0.4 的文字。
- **題型**（`noon.md` §1、§1a）：
  - 模式 A 選項題：題幹是 `plain_en`；選項是 `distractors` 加上 chunk，每次顯示時用 `sampleWithSeed(options, 4, seed)` 打散，`seed` 由 `crypto.getRandomValues` 產生（§4.14.4）。
  - 模式 A 自行回想：只顯示 `recallPrompt` 給的文字；先「看答案」才出現評分鈕。
  - 模式 B：`context_zh`＋照 `shuffled_order` 排的語塊；排出的**文字序列**等於 `blocks` 原順序就算對（重複的塊放哪個都可以）。
  - `ReviewRequest.mode`：模式 B 送 `'B'`，兩種模式 A 都送 `'A'`。
- **下次間隔**：評分鈕下方的「N 天後」「明天」用 `applyReview(card.schedule, rating, today, srs)` 算（和伺服器同一個函式），不在畫面寫死。
- **409**：`review` 回 `conflict`（今天已評過）→ 不顯示錯誤、算這張答完、直接下一張（#91 核准）。其他錯誤照 §5.0.4 顯示在卡片下方，評分鈕可以再按。
- **今天只有 N 張**（`noon.md` §2）：`card_ids` 少於 25 張時第一張卡上方顯示提示；組成的「到期舊卡」＝載入時 `schedule.dueDate` 不是 null 的卡、「新卡」＝是 null 的卡；`seedRemaining` 是 null 時不顯示「種子庫剩餘」。
- **rail**（只有電腦）：今日進度、組成、種子庫剩餘（同上規則）、「不用出聲・不需要麥克風」。今晚題目預覽（T-039）、「新增字卡」按鈕（T-034）不在本單。
- **測試工廠**：照 §9.1.7 的 `ApiClient` 工廠規則（組成根注入 `fetch` 與 token、畫面經 `useApi()`、測試用 `makeTestApiClient`；`apps/web/src/api/test/fakes.ts` 與組成根由 T-021 建、開工時一定已在 main；本單把六個方法的預設值加進 `fakes.ts`。兩個 QA 探針 `features/login/login-errors.qa.test.ts`、`src/app.qa.test.ts` 仍寫完整的 `ApiClient` 字面值、本單不能改（QA 的檔案），所以六個新方法在 `ApiClient` 介面上**暫時選填**（和 T-021 的 `tts`、`ttsSignedUrl` 同一個過渡，§9.1.7 過渡 1），呼叫端用 `??` 處理；改回必填由 T-020 之後第一張改 `ApiClient` 的單做（§9.1.7 過渡 3；TASKS 備註，建議 T-034），本單報告列出哪六個方法還是選填；若開工時兩個探針已改用工廠，就直接設必填、不用 `??`，報告寫明是哪一種）。

## 驗收標準

- **AC-T33-3**（AC-08、`noon.md` §1a）自行回想：題幹照 `recallPrompt` 的 `kind` 用對應的標籤與問句；作答前沒有評分鈕、答案框不含答案文字；按「看答案」後顯示 chunk、中文意思（題幹是中文意思時不重複）、有例句才顯示例句（chunk 粗體）；看了不能收回；任何時候題幹都不是 chunk 本身。

- **AC-T33-5**（AC-09、§4.2）三個評分鈕下方的下次間隔等於 `applyReview` 用目前 `srs` 算出的結果；按下送 `POST /reviews`（模式 B 送 `'B'`、模式 A 送 `'A'`），成功後下一張。
