## 介面
```ts
// apps/web/src/ui/theme.ts（T-018 的檔案，新增）
export function applyThemeColor(pref: ThemePreference, color: string, head?: HTMLHeadElement): void;
// apps/web/src/pwa/online.ts
export function subscribeOnlineStatus(onChange: (online: boolean) => void, target?: Window): () => void;
// apps/web/src/pwa/update.ts（register 預設是 virtual:pwa-register 的 registerSW）
export function watchForUpdate(onNeedUpdate: (apply: () => Promise<void>) => void, register?: RegisterSW): void;
```
- **manifest**（§9、ADR-007）：由 `vite-plugin-pwa` 產生；`start_url` 為 `/`、`display` 為 `standalone`；`theme_color` 只有一個值，是 `tokens.json` 的 `color.hero.light`（`#0F2236`），建置時從 `tokens.json` 讀，不另寫一份；`name`、`short_name`、`background_color`、圖示照「前置」補上的值。
- **SW**（§9；TechLead 決定）：`registerType: 'prompt'`；`generateSW`；precache 只放建置出的外殼（`html`、`js`、`css`、manifest、圖示）；**不設任何 runtime caching**，所以 Supabase origin（`/functions/*`、REST、Storage、Auth）與其他沒被 precache 的請求都直接走網路。TTS 音檔快取不在本單（T-021）。
- **新版**（§9）：`watchForUpdate` 在有新版時呼叫 `onNeedUpdate`；畫面顯示「更新」按鈕，按了才呼叫 `apply`（重新載入成新版）；不自動重整。
- **斷線**（NFR-06）：`subscribeOnlineStatus` 先用目前的 `navigator.onLine` 呼叫一次，之後跟著 `online`／`offline` 事件；回傳的函式取消訂閱。離線時顯示「需要連網」（`role="status"`），恢復連線後消失。
- **兩個提示的版面**：DESIGN.md 沒有專門規格，用 DESIGN §7 的既有元件與 token 組成，不新增顏色；本單只驗收文字、角色、尺寸與響應式。
- **`theme-color`**（ADR-014 決定 4、DESIGN §9）：`index.html` 在 §9.1.4 的第 4、5 項位置加兩個 `meta name="theme-color"`：`media="(prefers-color-scheme: light)"` 值 `#F4F5F7`、`media="(prefers-color-scheme: dark)"` 值 `#0A1420`（`color.theme-bar` 的淺、深值）。`applyThemeColor`：`system` → 恢復這兩個帶 `media` 的 meta；`light`／`dark` → 只留一個不帶 `media` 的 meta，值是傳入的 `color`（呼叫端在 `data-theme` 設好後讀 `--color-theme-bar` 的計算值）。啟動時與 `setThemePreference` 之後都呼叫它。

## 驗收標準
- **AC-T19-1**（§9、ADR-007）建出的 manifest：`start_url`、`display: "standalone"`、192 與 512 px 圖示各一、`theme_color` 等於 `tokens.json` 的 `color.hero.light`。
- **AC-T19-2**（§9、§7）SW 設定：`registerType: 'prompt'`；沒有 runtime caching；precache 清單只有同源的外殼檔案。
- **AC-T19-3**（§9、§7）E2E：SW 啟用後，Cache Storage 裡只有 preview 伺服器同源的網址，沒有 `/functions/` 或其他來源的網址。
- **AC-T19-4**（NFR-06）`subscribeOnlineStatus` 照「介面」；E2E 斷線時出現「需要連網」，恢復後消失；斷線後重新載入，外殼從 precache 顯示並出現「需要連網」。
- **AC-T19-5**（§9）`watchForUpdate` 與「更新」按鈕照「介面」：有新版才出現按鈕；沒按就不重新載入；按了呼叫 `apply` 一次。
- **AC-T19-6**（ADR-014 決定 4、DESIGN §9）`index.html` 的兩個 `theme-color` 位置、`media` 與值照「介面」，值等於 `tokens.json` 的 `color.theme-bar`。
- **AC-T19-7**（ADR-014 決定 4、AC-28）`applyThemeColor`：手動只留一個不帶 `media` 的 meta 且值正確；回到 `system` 恢復兩個；重複呼叫不會多出 meta；E2E 選「深色」後只剩一個 `#0A1420`。
- **AC-T19-8**（憲章 §15.8、NFR-01、DESIGN §5、§10）「需要連網」與「更新」在 360×640（Pixel 模擬）與 1280×800 都看得到、沒有橫向捲動；360 下「更新」按鈕 ≥48×48 CSS px；電腦版 Tab 到「更新」有 DESIGN §10 的 `:focus-visible` 外框。
