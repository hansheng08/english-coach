## 介面
```ts
// apps/web/src/ui/theme.ts（T-018 的檔案，新增）
export function applyThemeColor(pref: ThemePreference, color: string, head?: HTMLHeadElement): void;
// apps/web/src/pwa/online.ts
export function subscribeOnlineStatus(onChange: (online: boolean) => void, target?: Window): () => void;
// apps/web/src/pwa/update.ts（register 預設是 virtual:pwa-register 的 registerSW）
export function watchForUpdate(onNeedUpdate: (apply: () => Promise<void>) => void, register?: RegisterSW): void;
```
- **T-018 介面約定**（只依賴這些，不寫死 T-018 的內部結構）：`apps/web/src/App.tsx` 是外殼的根元件，mock 模式在每頁最上面放「預覽：假資料」；`ui/theme.ts` 匯出 `ThemePreference`、`setThemePreference`；`vite.config.ts` 用 `@vitejs/plugin-react` 與 `dataModeOrThrow`。
- **manifest**（pwa.md §1、ADR-007）：由 `vite-plugin-pwa` 產生。`name` `english-coach`、`short_name` `EN Coach`、`description` `每天 80 分鐘，把英文講得像 Senior。`、`lang` `zh-Hant-TW`、`dir` `ltr`、`start_url` `/`、`scope` `/`、`display` `standalone`；不設 `orientation`。`theme_color` 與 `background_color` 都是 `tokens.json` 的 `color.hero.light`（`#0F2236`），建置時從 `tokens.json` 讀，不另寫一份。
- **圖示**（pwa.md §1、§2）：四張 PNG，來源 `docs/design/assets/icons/` 的 `icon-192.png`、`icon-512.png`（`purpose: "any"`）與 `icon-maskable-192.png`、`icon-maskable-512.png`（`purpose: "maskable"`）；不用 `"any maskable"` 合併寫法。對外網址是 `/icons/<檔名>`。Claude 在 run-task 不能複製二進位檔（允許清單沒有 `cp`），所以**不 commit PNG**：建置時由 `apps/web/vite.pwa.ts` 從來源讀出、原樣輸出到建置產物的 `icons/`（只用 Node 內建模組），來源只有一份。
- **SW**（§9；TechLead 決定）：`registerType: 'prompt'`；`generateSW`；precache 只放建置出的外殼（`html`、`js`、`css`、manifest、四張圖示）；**不設任何 runtime caching**，所以 Supabase origin（`/functions/*`、REST、Storage、Auth）與其他沒被 precache 的請求都直接走網路。TTS 音檔快取不在本單（T-021）。
- **系統提示的疊放**（pwa.md §3.1）：`App.tsx` 在頁面頂端放 `.sysbars`（`position: sticky; top: 0`，z-index 45），由上到下是「預覽：假資料」（mock 時）、「需要連網」（離線時）；兩條都推開內容，不蓋住內容；第一條的上內距含 `env(safe-area-inset-top)`。預覽條元件本身不改（只改它被放在哪裡）。
- **斷線條**（pwa.md §3.2、NFR-06）：`subscribeOnlineStatus` 先用目前的 `navigator.onLine` 呼叫一次，之後跟著 `online`／`offline`；回傳的函式取消訂閱。離線時顯示整條：底 `ink`、字 `bg`、左邊斷線圖示 18px；粗體「需要連網」（獨立一個元素）＋「目前沒有網路，連上後再繼續。」；`role="status"`；不能關閉、沒有按鈕；恢復連線就消失；出現時 `ec-fade`（`motion-duration-base`）。
- **離線開啟的面板**（pwa.md §3.2）：外殼從 precache 開啟且離線時，內容區顯示斷線圖示＋「今天的課表要連網才能載入」＋「App 外殼已經開好，但課表、字卡和紀錄都在雲端，不存在這台裝置。連上網路後按「重新載入」。」＋次要按鈕「重新載入」（52px 高，按了重新載入頁面）。首頁實際的載入失敗狀態屬 T-026（pwa.md §4 #6），本單只做外殼層的這張面板。
- **新版卡片**（pwa.md §3.3、§9）：`watchForUpdate` 在有新版時呼叫 `onNeedUpdate`；畫面顯示卡片：`surface` 底＋`line` 細框＋`--shadow-float`、圓角 `lg`；左邊更新圖示（`ink-2`）、粗體「有新版本」＋「按更新會重新載入頁面。」、右邊 `.btn-2`「更新」（48px 高、寬 ≥88px）。`role="status"`，出現時不搶焦點；按「更新」呼叫 `apply` 一次，處理中按鈕 `disabled`。沒有「稍後」也沒有關閉鈕，卡片留到按下「更新」。不自動重整。出現時 `ec-up`（上移 16px＋淡入，`motion-duration-base`）。
- **新版卡片的位置**（pwa.md §3.3）：手機（<900px）左右各 12px、`bottom: calc(76px + env(safe-area-inset-bottom))`；電腦（≥900px）距右、下各 24px，寬 380px。手機上卡片出現時，內容區底部內距加大到 184px，最後一段內容不被蓋住。註：76px 是為底部分頁列預留的高度，T-018 還沒有底部分頁列，照規格值做，不另調。
- **之後加暫緩條件**：「要不要現在顯示卡片」只放在 `pwa/update.ts` 的一個判斷點，本單恆為顯示。之後 ARCHITECTURE §9 若加錄音中暫緩之類的條件（例如 `holdUpdatePrompt()`），只改這個判斷點，不改 AC-T19-7 的行為。
- **`theme-color`**（ADR-014 決定 4、DESIGN §9）：`index.html` 在 §9.1.4 的第 4、5 項位置加兩個 `meta name="theme-color"`：`media="(prefers-color-scheme: light)"` 值 `#F4F5F7`、`media="(prefers-color-scheme: dark)"` 值 `#0A1420`（`color.theme-bar` 的淺、深值）。`applyThemeColor`：`system` → 恢復這兩個帶 `media` 的 meta；`light`／`dark` → 只留一個不帶 `media` 的 meta，值是傳入的 `color`（呼叫端在 `data-theme` 設好後讀 `--color-theme-bar` 的計算值）。啟動時與 `setThemePreference` 之後都呼叫它。
- **動態**：`ec-fade`、`ec-up` 只放在 `prefers-reduced-motion: no-preference` 裡，減少動態時直接出現（DESIGN §6）。

## 驗收標準
- **AC-T19-1**（pwa.md §1、ADR-007）建出的 manifest 欄位與值照「介面」；`theme_color`、`background_color` 都等於 `tokens.json` 的 `color.hero.light`；沒有 `orientation`。
- **AC-T19-2**（pwa.md §1、§2）`icons` 剛好四張：192、512 各一張 `any`、一張 `maskable`，沒有合併的 `purpose`；每張的 `/icons/<檔名>` 都在建置產物裡，內容與 `docs/design/assets/icons/` 的來源位元組相同。
- **AC-T19-3**（§9、§7）SW 設定：`registerType: 'prompt'`；沒有 runtime caching；precache 清單只有同源的外殼檔案（含四張圖示）。
- **AC-T19-4**（§9、§7）E2E：SW 啟用後，Cache Storage 裡只有 preview 伺服器同源的網址，沒有 `/functions/` 或其他來源的網址。
- **AC-T19-5**（pwa.md §3.2、NFR-06）`subscribeOnlineStatus` 照「介面」；E2E 斷線時出現斷線條，文字、角色照「介面」，恢復後消失；斷線條沒有任何按鈕。
- **AC-T19-6**（pwa.md §3.2）斷線後重新載入：外殼從 precache 顯示、有斷線條，內容區是「離線開啟的面板」；按「重新載入」會重新載入頁面。
- **AC-T19-7**（pwa.md §3.3、§9）`watchForUpdate` 與新版卡片照「介面」：有新版才出現；沒按就不重新載入；按「更新」呼叫 `apply` 一次，處理中按鈕 `disabled`；沒有「稍後」或關閉鈕。
- **AC-T19-8**（pwa.md §3.1）mock 模式離線時，`.sysbars` 內由上到下是預覽條、斷線條，`position` 為 `sticky`、`top` 為 0；捲動後兩條仍在畫面頂端。
- **AC-T19-9**（pwa.md §3.3、§3.5、DESIGN §10）新版卡片的位置、尺寸與手機的底部內距照「介面」；「更新」按鈕高 ≥48、寬 ≥88；電腦版 Tab 到「更新」有 2px `gold-text` 外框、位移 2px。
- **AC-T19-10**（DESIGN §6）`prefers-reduced-motion: reduce` 時，斷線條與新版卡片出現時沒有動畫。
- **AC-T19-11**（ADR-014 決定 4、DESIGN §9）`index.html` 的兩個 `theme-color` 位置、`media` 與值照「介面」，值等於 `tokens.json` 的 `color.theme-bar`。
- **AC-T19-12**（ADR-014 決定 4、AC-28）`applyThemeColor`：手動只留一個不帶 `media` 的 meta 且值正確；回到 `system` 恢復兩個；重複呼叫不會多出 meta；E2E 選「深色」後只剩一個 `#0A1420`。
- **AC-T19-13**（憲章 §15.8、NFR-01）360×640（Pixel 模擬）、412、768、1280、1440 下，斷線條、離線面板、新版卡片都看得到且沒有橫向捲動；360 下「更新」「重新載入」都 ≥48×48 CSS px。

## 結束時
1. 在指定的分支上 commit 並 push，不得動 main。
2. 把結果寫到 docs/reports/T-019.md：完成摘要、變更檔案、測試結果、未完成事項、需要人類決定的問題。
3. 測試結果、突變結果、權限被拒以 workflow 自動產生的摘要與 PR 觸發的 CI run 為準，報告不重貼。
