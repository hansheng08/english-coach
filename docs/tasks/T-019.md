## 目標
讓 App 可以安裝（manifest、圖示）、外殼由 SW 快取而個資與 API 一律不快取、有新版時等使用者按「更新」才換、斷線時顯示「需要連網」，並讓 `theme-color` 跟著主題偏好變。

## 介面
```ts
// apps/web/src/sw/cache-policy.ts
export type CachePolicy = 'network-only' | 'default';
export function cachePolicyFor(url: URL, supabaseUrl: string | null): CachePolicy;
// apps/web/src/ui/theme.ts（T-018 的檔案，新增）
export function applyThemeColor(pref: ThemePreference, colors: { readonly light: string; readonly dark: string }, head?: HTMLHeadElement): void;
// apps/web/src/ui/online.ts
export function subscribeOnlineStatus(onChange: (online: boolean) => void, target?: Window): () => void;
```
- **manifest**（§9、ADR-007）：由 `vite-plugin-pwa` 產生；有 `name`、`short_name`、192／512 px 圖示、`start_url`、`display: "standalone"`；`theme_color` 只有一個值，用淺色 `--color-hero`（值待 #54）。
- **SW**（§9）：`registerType: 'prompt'`；外殼 precache；`cachePolicyFor`：網址的 origin 和 `supabaseUrl` 相同（含 `/functions/*`、REST、Storage、Auth）→ `network-only`；`supabaseUrl` 為 `null`（`mock` 模式）或其他網址 → `default`（交給 precache 與瀏覽器）。SW 的 runtime caching 用這個函式，不另寫一份規則。
- **新版**（§9）：有新版時顯示「更新」按鈕，按了才重新載入；不自動重整。
- **斷線**（NFR-06）：`subscribeOnlineStatus` 先用目前的 `navigator.onLine` 呼叫一次，之後跟著 `online`／`offline` 事件；回傳的函式取消訂閱。離線時顯示「需要連網」。
- **`theme-color`**（ADR-014 決定 4、§9.1.4）：`index.html` 加兩個 `meta name="theme-color"`，分別帶 `media="(prefers-color-scheme: light)"`、`(prefers-color-scheme: dark)`，放在 §9.1.4 的第 4、5 項位置。`applyThemeColor`：`system` → 恢復這兩個帶 `media` 的 meta；`light`／`dark` → 只留一個不帶 `media` 的 meta，值是對應的顏色。`setThemePreference` 之後呼叫它。

## 驗收標準
- **AC-T19-1**（§9、ADR-007）建出的 manifest 有 `name`、`short_name`、`start_url`、`display: "standalone"`、192 與 512 px 圖示各一，`theme_color` 只有一個值。
- **AC-T19-2**（§9、§7）`cachePolicyFor` 照「介面」：Supabase origin 的任何路徑都是 `network-only`；其他與 `null` 都是 `default`。
- **AC-T19-3**（§9）SW 的設定是 `registerType: 'prompt'`，runtime caching 只用 `cachePolicyFor` 判斷。
- **AC-T19-4**（NFR-06）`subscribeOnlineStatus` 照「介面」：先回報目前狀態、跟著事件更新、取消後不再呼叫。
- **AC-T19-5**（ADR-014 決定 4）`index.html` 的兩個 `theme-color` 在 §9.1.4 的第 4、5 項位置，`media` 照「介面」。
- **AC-T19-6**（ADR-014 決定 4、AC-28）`applyThemeColor`：`light`／`dark` 只留一個不帶 `media` 的 meta 且值正確；回到 `system` 恢復兩個帶 `media` 的 meta；重複呼叫不會多出 meta。
