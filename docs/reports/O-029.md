## 設計決定
- 後端名稱用子字串比對；`VITE_` 用 `VITE_[A-Za-z0-9_]*` 取最長名稱，再與白名單做精確比對（區分大小寫）。
- 檔案以位元組讀入、用 latin1 解碼。符號連結（含掃描根目錄本身）、0 個檔、讀檔失敗都回 INPUT（exit 2）。
- `scanText` 收到非字串時拋 `TypeError`，不回空陣列。
- CLI 命中行固定三欄（路徑、名稱、種類），不印內容。
- TC-10 的突變測試：讀原始碼、做文字替換、寫到暫存資料夾後重新載入，並要求完整檢查至少一項失敗；替換樣式找不到時測試會失敗，避免靜默失效。
- 測試資料都在執行時建在暫存資料夾，沒有 commit 含後端名稱的 fixture。
