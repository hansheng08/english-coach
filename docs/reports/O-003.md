說明：CLI 3.2.0 本機 Auth 簽發的**使用者** access_token 是 **ES256**，`status -o env` 的 `JWT_SECRET` 只能核對 HS256（例如 ANON_KEY，`role=anon`）。對使用者 JWT 改打 Auth `/user` 已得 HTTP 200，但回應是 user 列（`id`）不是 JWT payload（`sub`），探針因此仍 401。`7125369` 已改為接受 `id`，但該次 CI 在 `ANON_KEY` 又出現 502，沒有驗證 200。
