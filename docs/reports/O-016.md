## 設計決定
- 規格沒寫死的地方，我這樣定：
  - `day.jobs`、`by_workflow.jobs` 只算已完成且計費的 job；`runs` 是有計費 job 的相異 run 數。
  - `projected_cycle_minutes` 用四捨五入取整。
  - `reasons` 同一族只留最嚴重的一個：`daily-stop` 蓋過 `daily-warn`；`exhausted` 蓋過 `month-stop` 蓋過 `month-warn`。`projected-over` 獨立。
  - 超出週期窗口的 job 先略過、不驗證；窗口內的 completed job 才驗證 runner 與時間。
  - `summarize` 的輸入多一個選填 `repo`（CLI 會傳），沒給時輸出 `null`。
- `summarize` 與 `billedMinutes` 的 error 物件多帶一個 `rule` 欄位，讓 CLI 對應到規則代碼。
- 抓取：每個 run 另查 jobs；runs 一頁不滿 100 筆就停，再比對 `total_count`。
