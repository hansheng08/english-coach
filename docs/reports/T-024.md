## 設計決定
- issue 依 zod 的 path 對應規則編號；`items.<i>.tags.<k>` 這類深層 path 截到欄位層級，同一規則在同一 path 只回一條。
- `batch` 不是數字時只檢查檔名格式，不比對 `<n>`；檔名要求 `batch-<n>.json` 且 `<n>` 沒有前導 0。
- 算 repo 根目錄用 `fileURLToPath(import.meta.url)` 加 `join(..., '..')`，沒有用全域 `URL`（`lib` 沒有 DOM，不想為此在 `node-builtins.d.ts` 宣告 `URL`）；`d.ts` 只多宣告 `ImportMeta.url`。
- drift 讀檔層收 `batch-*.json`（不限數字），讓 `batch-7.json`、`batch-01.json` 能被比對函式判為失敗。
- 工廠 `makeSeedChunk(overrides, index)`、`makeSeedBatch(overrides)`：不同 `batch` 的內容互不重複，可互當 `others`。
