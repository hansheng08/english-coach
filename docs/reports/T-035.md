- 新增 `apps/web/src/features/resume/redact.ts`：純函式 `redactPii`，依序處理 Email → 電話（台灣手機、市話、美國）→ 地址（台灣英文、美國、中文），換成 `[email]`／`[phone]`／`[address]` 並回傳 `removed` 計數；不 import 任何模組。
- 新增 `extract.ts`：`extractResumeText`、`defaultExtractDeps`、相關型別。類型判斷、PDF 組字、三種 `validation` 錯誤照任務單；成功時不去個資；例外一律轉成 `err`。
- `defaultExtractDeps` 只在呼叫時用動態 `import()` 載入 `pdfjs-dist`、`mammoth`；pdf.js worker 用 `pdfjs-dist/build/pdf.worker.mjs?url` 取得網址（已確認該路徑存在於 6.5.438）。
- `apps/web/package.json` 的 `dependencies` 只加 `pdfjs-dist`（`^6.0.0`）與 `mammoth`（`^1.0.0`），以單獨一條 `pnpm install --no-frozen-lockfile` 更新 `pnpm-lock.yaml`。
- 測試：`redact.test.ts`（TC-1～12、TC-18）、`extract.test.ts`（TC-13～16）、`deps.test.ts`（TC-17）。`pnpm check` 通過。

## 設計決定
- 美國號碼：整串剛好 10 位數字、沒有 `+1` 時，在比對後排除（保留原樣）。11 位連寫（`14155550123`）仍會換掉。
- 美國地址的「城市、州」只在後面接郵遞區號時才併入；沒有郵遞區號的城市與州不併入。
- 台灣英文地址：`No.` 之後逐段（以 `,` 分開）判斷，遇到第一段不符合就停；最後一段尾端的空白保留在標記之後。
- 中文地址：為避免把前面的句子吞掉，本體必須從「兩個漢字＋市／縣」開始（例如 `台北市`、`新竹縣`）。這比任務單的「含市或縣」更嚴格，沒有縣市開頭的中文地址不會被換掉。
- 已知取捨：`06-2019-2021` 這種「0＋區碼＋兩組四位數」的月份區間，形式上等同市話，會被換成 `[phone]`。
