## 完成摘要
新增三支只用 `node:` 內建模組的 fail-closed 檢查腳本，以及共用解析模組與 Vitest 測試：
- `task-lint`：任務單格式（TL-* 規則共 15 條）。
- `scope-check`：分支變更只能落在任務單「檔案範圍」（SC-*）。

`vitest.config.ts` 的 `include` 加入 `tooling/**/*.test.mjs`。本單 `docs/tasks/O-008.md` 自身通過 task-lint（TC-2）。

## 設計決定
- 所有 CLI 把 `run(argv)` 做成回傳 `{code, stdout, stderr}` 的純函式；進入點 `runCli` 把未捕捉例外轉成 exit 1，並只用 `process.exitCode`，沒有 `process.exit(0)`。
- `parseTaskFile` 多回傳 `hasDo`、`acDefs`、`hasTcHeader`（介面型別的超集），供 lint 與 scope-check 使用。
- `ac-coverage` 對 JSON 形狀嚴格檢查（缺 `assertionResults`、`fullName`、`status` 都算 `INPUT`）。
- 子標題「### 其他角色」的路徑依規格併入允許清單。
- fixtures 放在 `tooling/fixtures/tasks/`；測試以 `O-901.md` 為基底做變異。
